Un **workflow social pour créateurs** retire des décisions du jour de publication. Un flux unique, c’est un brief, une relecture, et un chemin vers la file. Vous pouvez le tenir une semaine où le travail client a déjà pris le jeudi.

Pour un créateur solo qui publie déjà chaque semaine et perd la soirée dans les onglets. Mauvais cadre si vous publiez une fois par mois, ou si chaque post est un tournage nouveau sans forme réutilisable. Dans ces cas, un dossier et un rappel suffisent.

## Partir des canaux que vous tiendrez vraiment

Deux réseaux principaux et un emplacement que vous avez le droit d’ignorer. Les deux principaux sont ceux où une semaine silencieuse se voit, pour vous. L’emplacement en plus reçoit un post seulement quand le même fichier convient. Si un canal reste silencieux deux semaines, il n’est pas dans le flux. Retirez-le jusqu’à ce qu’il vous manque pour une raison concrète, par exemple un acheteur qui ne vous parle que là.

Une ligne tenable pour beaucoup de créateurs solo : LinkedIn plus Instagram, ou un réseau visuel plus l’endroit où le lien doit vivre. Cinq profils avec un post chacun, c’est un plan d’équipe. Deux profils avec un fichier que vous retrouvez, c’est un plan solo.

## Fixer trois formats répétables

Les formats raccourcissent la page blanche. Trois suffisent, en rotation :

- Expliquer : un point et un exemple tiré d’un travail que vous avez fait.
- Preuve : un résultat, un commentaire reçu, ou un avant-après du travail.
- Offre : un lien, seulement une semaine où vous avez quelque chose à montrer.

Une semaine normale, c’est expliquer, puis preuve. Les semaines d’offre sont rares exprès. Sans offre, n’en inventez pas pour remplir la case. La case vide, c’est le système qui fonctionne.

Écrivez la rotation là où vous la verrez le lundi, sur la même note que le brief. Changer la liste de formats chaque semaine ramène le flux à l’improvisation.

## Écrire le brief avant d’ouvrir un outil

Le brief tient en six lignes. S’il est vide, l’outil d’écriture et l’app de design inventeront chacun un post différent.

<ul class="blog-checklist">
  <li>Pour qui, en une ligne</li>
  <li>Le seul point</li>
  <li>La preuve que vous avez déjà, ou « aucune »</li>
  <li>Le lien, ou « aucun »</li>
  <li>Le format : expliquer, preuve, ou offre</li>
  <li>Les deux réseaux que ce post utilise</li>
</ul>

Un exemple rempli, pour quelqu’un qui conseille et publie sur LinkedIn :

- Pour qui : des consultants solo qui publient entre deux appels clients
- Point : le lent est de retrouver le fichier de la semaine dernière, pas de trouver un sujet
- Preuve : vous avez refait un carrousel parce que l’export n’avait pas de nom
- Lien : aucun
- Format : expliquer
- Réseaux : LinkedIn, et Instagram seulement si la même image se lit encore en petit

Cette note est le post. Les outils sont la sortie. Rédigez la légende à partir de ces lignes, puis arrêtez d’ajouter des points. Une seconde idée devient un second post la semaine suivante.

## Relier brouillon, visuel et file

Le flux casse quand l’un des trois n’a aucun renvoi vers les autres. Pas besoin d’une base. Il faut un nom.

<ol class="blog-flow">
  <li><strong>Brief</strong><p>Six lignes dans une note, datée.</p></li>
  <li><strong>Légende</strong><p>Accroche et point pris dans le brief, pas dans un prompt neuf.</p></li>
  <li><strong>Fichier</strong><p>La même date et le même format dans le nom.</p></li>
  <li><strong>Relecture</strong><p>Première ligne, lien, recadrage. Un passage.</p></li>
  <li><strong>File</strong><p>Les deux réseaux. Ne changez que les lignes que votre règle nomme.</p></li>
</ol>

La règle de légende peut être une phrase sous le brief : même accroche sur les deux, lien seulement là où le clic compte, texte plus court sur le réseau visuel. Si vous ne pouvez pas dire la règle, vous réécrirez le post deux fois et vous appellerez ça du contrôle qualité.

Relisez avant la file, pas après avoir collé dans les deux compositeurs. Corriger un mauvais lien à deux endroits, c’est le passage que vous essayez d’enlever.

## Le compromis, et quand s’arrêter

La première semaine est plus lente. Vous écrivez le brief et vous nommez les fichiers alors que les posts sont aussi dus. Gardez quand même les deux réseaux et les trois formats. À la troisième semaine, le brief devrait être l’étape longue, et la file un collage que vous ne redessinez pas.

Arrêtez d’ajouter des étapes quand vous pouvez publier les posts de la semaine à partir du brief, sans une quatrième app. Statistiques, fils de concurrents et recherche de hashtags n’ont pas leur place dans la même séance. Ils ramènent les clics. Un autre jour, ou pas du tout, tant que le chemin de publication n’est pas devenu ennuyeux.

Ce système échoue dans deux cas nets. Si vous publiez une fois par mois, vous oublierez les règles, et un rappel de calendrier est plus honnête. Si chaque post est une production sur mesure, une nouvelle vidéo avec son propre script, il vous faut un calendrier de production. Un flux unique suppose que la forme se répète.

## Questions fréquentes

<div class="blog-faq">
  <h3>C’est réservé aux agences ?</h3>
  <p>Non. Les agences ont déjà des rôles pour le brief et la file. Le créateur solo sent le passage parce que la même personne tient les deux rôles le même soir.</p>
</div>

<div class="blog-faq">
  <h3>Faut-il un planificateur dès le premier jour ?</h3>
  <p>Seulement si vous publiez quand vous n’êtes pas devant l’écran. Un planificateur natif sur un réseau suffit, jusqu’à ce que le second réseau vous fasse coller le même post deux fois par semaine.</p>
</div>

<div class="blog-faq">
  <h3>Que mesurer ?</h3>
  <p>Les minutes entre un brief fini et des posts dans la file sur les réseaux choisis, et si vous avez ouvert plus d’apps que le flux n’en prévoit. Laissez les abonnés en dehors de cette décision.</p>
</div>

<div class="blog-faq">
  <h3>À quelle fréquence revoir le flux ?</h3>
  <p>Quand vous ajoutez ou retirez un canal, ou quand la même étape fait mal trois semaines de suite. Réécrire chaque trimestre un flux qui tient est facultatif.</p>
</div>
