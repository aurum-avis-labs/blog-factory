## Fehler im Kausalschleifen-Diagramm

<p class="blog-lede">Ein Kausalschleifen-Diagramm kann fertig aussehen und im Entscheidungstermin trotzdem scheitern, wenn Spaghetti-Kanten, fehlende Polarität oder Schuld-Labels die Mechanik verdecken.</p>

**Fehler im Kausalschleifen-Diagramm** sind meist Tempo-Fehler: zu viele Pfeile ohne Satz, Vorzeichen, die niemand geprüft hat, Variablen, die eine Person statt einen Druck benennen, Schleifen ohne Namen und Karten ohne Verzögerung. Wenn diese fünf Punkte stimmen, trägt die Karte einen Entscheid.

Die Seite ist für Leute, die schon eine Skizze, ein Whiteboard-Foto oder eine Datei haben, die sie weiterleiten wollen. Fehlt ein wiederkehrendes Ergebnis, zuerst den [Kausalschleifen-Workshop](/de/blog/kausalschleifen-workshop-anleitung) machen und mit etwas Editierbarem zurückkommen. Zum Lesen einer fremden Karte, ohne sie neu zu zeichnen, eignet sich [Kausalschleifen-Diagramm lesen](/de/blog/kausalschleifen-diagramm-lesen).

## Schnellcheck vor dem Versand

<ul class="blog-checklist">
  <li>Schuldzuweisungen in neutrale Variablen umbenennen</li>
  <li>Polarität an jeder Kante markieren, bevor jemand einen Fix vorschlägt</li>
  <li>Schleifen schliessen, indem Sie die Pfeile nachziehen, nicht indem Sie Knoten gruppieren</li>
  <li>Jede Kante löschen, die niemand laut aussprechen kann</li>
</ul>

## Spaghetti ohne Geschichte

Spaghetti sind Pfeile zwischen benachbarten Wörtern, weil sie sich ähnlich anfühlen, nicht weil jemand die Ursache sagen kann. Der Test ist kurz. Nehmen Sie die Ergebnisvariable und lesen Sie einen Pfad laut, Pfeil für Pfeil, in einem Atemzug. Muss die Person innehalten, auf ein Cluster zeigen und sagen, alles hänge zusammen, ist die Kante Dekoration.

Splitten Sie die Variable, wenn ein Nomen zwei Mechanismen versteckt. «Qualität» kann im einen Satz die Fehlerquote sein und im nächsten die Nacharbeitsstunden. Löschen Sie die Kante, wenn der Satz nur die Beschriftung wiederholt. Eine dichte Karte bleibt brauchbar, wenn jeder verbliebene Pfeil einen Satz hat und die Gruppe das Ergebnis in unter einer Minute findet.

Hören Sie auf, Pfeile zu ergänzen, sobald neue Kanten die Schleifen nicht mehr ändern, die Sie wirklich testen würden. Zusätzliche Verbindungen machen die Karte nicht strenger. Sie verdecken den Pfad, über den der Raum streiten muss.

## Fehlende oder widersprüchliche Polarität

Jede Kante braucht einen prüfbaren Satz: steigt A, steigt B, oder steigt A, fällt B. Das ist die Polarität. Schreiben Sie sie an den Pfeil, bevor jemand einen Eingriff vorschlägt. Ein fehlendes Vorzeichen wirkt klein. Es ändert, welche Schleife verstärkend und welche ausgleichend ist. Der empfohlene Test kann dann in die falsche Richtung zeigen.

Die heikle Variante sieht fertig aus. Eine Person hat «Überstunden hoch, Fehler runter» markiert, weil das die gewünschte Politik war. Eine andere hat «Überstunden hoch, Fehler hoch» markiert, weil die Tickets vom letzten Quartal das gezeigt haben. Das sind zwei Hypothesen. Beide bleiben nur, wenn Sie sie als alternative Kanten zeichnen und markieren, welche der nächste Test meint. Ein leerer Pfeil ist der Mittelweg, der nichts sagt.

Lesen Sie drei Kanten vom Ergebnis, bevor die Gruppe über Eingriffe diskutiert. Klingt ein Satz absurd, oder kann niemand die Zeitskala nennen, korrigieren Sie Vorzeichen oder Variable, bevor das Gespräch weitergeht.

## Schuld-Variablen

«Schlechte Führung», «Silokultur» und «widerstrebende Mitarbeitende» wirken im Raum präzise und scheitern auf der Seite. Sie benennen eine Person oder eine Stimmung. Ein Kausalschleifen-Diagramm braucht einen Druck, den eine andere Person beobachten könnte. Übersetzen Sie das Schuld-Label, bevor Sie den Pfeil zeichnen.

| Was gesagt wird | Was Sie kartieren können |
|---|---|
| Schlechte Führung | Entscheidungslatenz oder widersprüchliche Ziele |
| Schlechte Kommunikation | Fehlende gemeinsame Priorität oder verspäteter Status |
| Wenig Ownership | Unklare Entscheidungsrechte oder keine geschützte Zeit |

Die umbenannte Variable besteht einen einfachen Test: könnten zwei Kolleginnen und Kollegen anhand von etwas Sichtbarem streiten, ob sie sich diesen Monat bewegt hat? Wenn nein, ist es immer noch ein Label. Das Urteil bleibt in den Notizen. Der beobachtbare Druck steht auf der Karte.

## Unbenannte Schleifen

Eine Schleife ohne Namen überlebt die Weiterleitung nicht. Wenn Sie einen Pfad geschlossen haben, geben Sie ihr einen Klartextnamen und einen Typ: R1 für verstärkend, B1 für ausgleichend. «R1: Überstunden-Spirale» reicht. «Die Schleife links» reicht nicht, weil links wandert, sobald jemand das Layout umstellt.

Benennen Sie nur Schleifen, die die Gruppe im Entscheid erwähnen würde. Zwei bis vier Namen sind für eine erste Karte normal. Acht Namen heisst, Sie dokumentieren das ganze System und das Briefing, das niemand liest. Der Rest gehört in einen Anhang oder in einen zweiten Durchgang.

Der Name muss zur Geschichte passen, nicht zur Zeichnung. Heisst R1 «Überstunden-Spirale», muss eine neue Leserin Überstunden, Fehler, Nacharbeit und wieder Überstunden nachziehen können, ohne zu fragen, welche Pfeile gemeint waren.

## Karten ohne Verzögerung

Eine Karte ohne Verzögerung setzt die falsche Uhr auf den Eingriff. Die ausgleichende Reaktion kann real sein und in der Kennzahl, die der Sponsor beobachtet, trotzdem unsichtbar bleiben. Teams brechen den Test dann ab, legen ein zweites Programm darauf und die ursprüngliche Schleife schliesst sich nie.

Markieren Sie eine Verzögerung an jeder Kante, deren Wirkung langsamer sichtbar wird als der Rhythmus der Sitzung: Einstellung und Training, Vertrauen, Zertifizierung, Lager, Budgetzyklen. Eine Randnotiz mit einer Spanne reicht. «Die Zertifizierung ist ein bis zwei Quartale später fertig» ist brauchbar. «Irgendwann» ist es nicht.

Erfinden Sie keine Dauer, damit die Karte vollständig wirkt. Kann die Gruppe keine Spanne nennen, schreiben Sie «Verzögerung, Dauer unbekannt» und behandeln Sie das als Annahme, nicht als Grund für einen kürzeren Piloten.

## Qualitätsgate vor dem Weiterleiten

Bitten Sie zwei Personen, die nicht hauptsächlich gezeichnet haben, die Schleifen unabhängig nachzuziehen. Geben Sie ihnen das Ergebnis, die Variablenliste und zehn Minuten. Zurückkommen sollten dieselben Schleifennamen, dieselbe Polarität auf den Kanten innerhalb dieser Schleifen und dieselbe Verzögerung, die das Testfenster setzt.

Weichen die Geschichten ab, ist die Struktur nicht reif für eine Weitergabe nach oben. Korrigieren Sie die Kante oder das Label, an dem sie gestolpert sind. Eine Titelfolie erklärt die Verwirrung nicht. Derselbe Check gilt für eine Datei aus einer Software: zwei Lesende, niemand erklärt im Raum, jede Person schreibt eine Spur.

## Rotstift an einer bestehenden Skizze

Nehmen Sie die Karte von letzter Woche, keinen neuen Workshop. Wenn bei Ihnen nur Notizen liegen, üben Sie an dieser Skizze. Ergebnis: monatlich entwischte Fehler. Variablen schon auf der Seite: Überstunden, Review-Zeit pro Änderung, offene Fehler, Release-Druck, Stunden auf Incidents, «schlechte Planung».

Löschen Sie drei Kanten ohne Satz. Typische Kandidaten: eine Linie von «schlechter Planung» zu allem, eine Linie von Release-Druck zu Stimmung ohne Definition von Stimmung, und ein Doppelpfeil, der nur sagt, die Dinge beeinflussten sich. Benennen Sie «schlechte Planung» in Entscheidungslatenz oder späte Scope-Änderungen um, je nachdem, welche Geschichte die Gruppe wirklich erzählen kann. Ergänzen Sie die Polarität an zwei Waisen, die schon einen Satz haben, zum Beispiel «Überstunden hoch, Review-Zeit pro Änderung runter» und «offene Fehler hoch, Release-Druck hoch». Schliessen Sie eine Schleife und benennen Sie sie. Schreiben Sie die Verzögerung dazu: gekürzte Review-Zeit zeigt sich in entwischten Fehlern später als im wöchentlichen Überstundenbericht.

Ändert dieser Durchgang die Schleife, die Sie testen würden, war die Karte nicht entscheidungsreif. Ändert er nur Formulierungen, können Sie sie teilen.

## Häufige Fragen

<div class="blog-faq">
  <h3>Wie viele Variablen gehören auf eine erste Karte?</h3>
  <p>Drei bis sechs Kernvariablen reichen für die meisten Entscheide im Team. Eine Variable kommt dazu, wenn eine Geschichte ohne sie auseinanderläuft. Zehn bis fünfzehn gehören in einen späteren Durchgang, nachdem eine Schleife einen benannten Test hat.</p>
</div>

<div class="blog-faq">
  <h3>Sollen wir die Zeichnung korrigieren oder neu anfangen?</h3>
  <p>Neu anfangen, wenn das Ergebnis noch keinen Namen hat oder die meisten Labels Schuldzuweisungen sind. Sonst editieren: Kanten ohne Satz löschen, Polarität ergänzen, eine verstärkende und eine ausgleichende Schleife benennen, die längste Verzögerung auf dem Pfad markieren, den Sie testen könnten.</p>
</div>

<div class="blog-faq">
  <h3>Kann eine ordentliche Karte trotzdem falsch sein?</h3>
  <p>Ja. Polarität und Namen machen die Behauptungen sichtbar. Sie beweisen sie nicht. Behandeln Sie jede verbliebene Kante als Hypothese und notieren Sie, welche Beobachtung sie schwächen würde, bevor Sie einen Fix empfehlen.</p>
</div>
