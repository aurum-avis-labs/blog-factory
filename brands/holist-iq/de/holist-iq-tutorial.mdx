Eine leere Seite lässt Systemarbeit abstrakt wirken, auch wenn das Problem konkret ist: ein Geschäftsergebnis, das zurückkam, eine Regel, die immer wieder umgangen wird, eine Forschungsfrage, warum eine Reform verblasst, oder ein ähnlicher Knoten in einem anderen Feld. Dieses **Holist-IQ Tutorial** ist ein kurzer Weg zu einer ersten Feedbackschleifen-Karte und zu einer Aktion, die Sie testen können.

Holist-IQ ist eine Systemdenken-Plattform für diese Aufgabe. Sie beschreiben eine Herausforderung in Klartext. Die Plattform hilft, die Kerndynamik zu kartieren, versteckte Schleifen sichtbar zu machen, Hebelpunkte zu zeigen und einen Entscheid mit mehr Voraussicht vorzubereiten als eine Liste von Symptomen. Es ist Entscheidungsunterstützung. Ein Bild, das Sie nie wieder ansehen, leistet diese Arbeit nicht.

Sie müssen nicht alles modellieren. Sie brauchen genug Struktur, um die Schleifen zu sehen, die das Ergebnis an Ort halten. Planen Sie für den ersten Durchgang etwa zwanzig Minuten. Den Platz des Produkts im weiteren Werkzeugkasten vor dem Start lesen Sie im [Holist-IQ-Leitfaden](/de/blog/holist-iq).

## Was Sie am Ende haben

Ein kleines Diagramm mit einem lesbaren Kern, eine verstärkende und eine ausgleichende Schleife, einen Hebelpunkt, den Sie in zwei Wochen anfassen können, und ein Experiment mit den Annahmen an konkreten Kanten. Nehmen Sie ein lebendiges Problem. Ein hypothetisches versteckt, welche Kante sich falsch anfühlt.

## Schritt 1: Ein messbares Ergebnis wählen

Schreiben Sie einen Satz.

- "Wir wollen die Kundenabwanderung in den ersten 30 Tagen senken." Das ist ein Geschäftsergebnis.
- "Wir wollen verstehen, warum diese Regulierung immer wieder umgangen wird." Das ist ein politisches Ergebnis.
- "Wir wollen nachvollziehen, warum dieses systemische Problem trotz Reformen wieder auftaucht." Das ist ein Forschungs- oder Rechercheergebnis.
- "Wir wollen sehen, warum ein Advocacy-Erfolg innerhalb eines Gesetzgebungszyklus erodiert." Das ist ein Ergebnis aus dem öffentlichen Interesse.

Ergänzen Sie eine grobe Kennzahl, wenn Sie eine haben: Abwanderungsrate, Rückstandsgrösse, Durchlaufzeit, eine Beschwerdezahl, eine Fehlerquote. Die Kennzahl hält die Karte an etwas, das Sie beobachten könnten. Haben Sie noch keine Kennzahl, halten Sie den Satz konkret genug, dass eine Kollegin sagen könnte, ob das Ergebnis besser oder schlechter wurde. "Alignment verbessern" überlebt Schritt 3 nicht.

In Holist-IQ starten Sie bei dieser Herausforderung in Klartext. Bleiben Sie in diesem Durchgang bei einem Ergebnis. Ein zweites Ergebnis ist eine zweite Karte.

## Schritt 2: Die Variablen listen, die das Ergebnis beeinflussen

Sammeln Sie Treiber und debattieren Sie sie noch nicht. Für frühe Abwanderung ist eine brauchbare Liste:

- abgeschlossenes Onboarding
- Zeit bis zum Nutzen
- Produktkomplexität
- Reaktionszeit im Support
- Erwartungsabweichung
- wahrgenommener Nutzen
- Vertrauen der Kundschaft

Nehmen Sie auf, worüber schon gestritten wird, auch die unbequemen Punkte, damit eine versteckte Schleife eine Chance hat. Halten Sie einen Kern, den Sie lesen können, und lassen Sie die weitere Liste auf 10 bis 15 Variablen wachsen, wenn die Nebenpunkte echt sind. Zu wenige, und Sie zeichnen eine Gerade und nennen sie ein System. Zu viele im Kern, und Sie sehen in zwanzig Minuten keine Schleife. Parken Sie den Rest auf einer Nebenliste, statt ihn im Ärger zu löschen.

Variablennamen sind Nomen, deren Bewegung Sie beobachten könnten. "Schlechtes Onboarding" ist ein Urteil. "Abgeschlossenes Onboarding" ist eine Variable.

## Schritt 3: Variablen mit Ursache und Wirkung verbinden

Fragen Sie bei jeder Kante: wenn dies steigt, steigt oder fällt jenes, wenigstens irgendwann? Schreiben Sie den Satz, bevor Sie den Pfeil zeichnen.

- "Höhere Produktkomplexität erhöht Support-Tickets."
- "Längere Reaktionszeit im Support erhöht Frustration."
- "Höhere Frustration erhöht Abwanderung."

Zeigt sich die Wirkung später, markieren Sie an dieser Kante eine Verzoegerung. Dort werden vernünftige Pläne früh abgebrochen, weil die Kennzahl, die Leute beobachten, sich noch nicht bewegt hat. Einstellung ist eine typische Verzoegerung. Eine Textänderung, die auf ein Release wartet, ist eine andere. Lassen Sie die Verzoegerung nicht als das Wort "irgendwann" stehen.

Notieren Sie auch die Richtung. Eine Kante ohne Richtung ist eine Themen-Assoziation, und die Aufgabe von Holist-IQ ist die Kausalstruktur, keine Mindmap verwandter Wörter. Wo Sie unsicher sind, behalten Sie den Satz und markieren ihn als Annahme. Die sammeln Sie in Schritt 7.

## Schritt 4: Die ersten Feedbackschleifen finden

Suchen Sie eine Kette, die zu ihrem Anfang zurückkehrt. Diese Rückkehr unterscheidet eine Ursachenliste von einem System.

**Eine verstärkende Schleife.** Komplexität steigt, Tickets steigen, Reaktionszeiten werden schlechter, Frustration steigt, Abwanderung steigt, der Druck, mehr Features zu liefern, steigt, Komplexität steigt. Benennen Sie sie so, dass das Team sie wiederholt, etwa "Feature-Druck-Schleife" oder "Support-Spirale".

**Eine ausgleichende Schleife.** Tickets steigen, Einstellungen steigen, Kapazität steigt, Reaktionszeiten verbessern sich, Frustration sinkt, Tickets stabilisieren sich. Benennen Sie auch diese, etwa "Einstellungs-Aufholschleife". Markieren Sie die Verzoegerung bei der Einstellung. Ohne sie wirkt die ausgleichende Geschichte schneller, als die Organisation ist.

Namen sind praktisch. Jemand kann auf die Schleife verweisen, ohne sie neu zu zeichnen, und das braucht die Abstimmung in der nächsten Sitzung. Wie diese Schleifentypen in operativen Entscheiden wirken, steht in [Systemdenken im Unternehmen](/de/blog/systemdenken-im-unternehmen).

Hören Sie auf, wenn Sie je eine haben oder wenn ein Typ ehrlich fehlt. Eine fehlende ausgleichende Schleife ist ein Befund. Sagen Sie das und prüfen Sie, ob eine Wirkung in eine Variable zurückfliesst, die Sie von der Seite gelassen haben. Holist-IQ hilft, diese versteckten Schleifen und die Wirkung einer Kante auf den Rest der Karte zu zeigen, damit der Rückweg sichtbar ist, bevor Sie eine Aktion wählen.

## Schritt 5: Einen Hebelpunkt bestimmen

Fragen Sie, wo eine kleine Änderung die Schleife verschieben könnte, die Sie wirklich haben, und wo Sie in den nächsten zwei Wochen die Befugnis haben, es zu versuchen. Orte, an denen Sie suchen können, als Liste und nicht als Versprechen:

- eine Verzoegerung, die Sie kürzen können, etwa früheres Erkennen von stockendem Onboarding
- Information, die Leute nicht teilen, etwa eine Abschlusszahl nach Segment
- ein Anreiz, der die verstärkende Schleife belohnt, etwa Features liefern, während die Support-Last schon hoch ist
- Reibung auf dem Pfad, den Sie wollen, etwa zusätzliche Schritte, unklare Übergaben oder Freigabe ohne Kriterien

Wählen Sie einen Punkt, der auf einer benannten Schleife sitzt und den Sie in zwei Wochen bewegen können. Eine Idee, die diese Schleife nicht berührt, kann auf der Nebenliste warten.

Holist-IQ ist da, um diese Punkte aus der Struktur zu zeigen, die Sie kartiert haben. Sie wählen trotzdem, welchen Sie testen.

## Schritt 6: Die Karte in eine testbare Aktion überführen

Schreiben Sie ein Experiment in dieser Form.

- **Wenn** wir X ändern,
- **erwarten wir**, dass Y, ein Frühindikator, sich innerhalb der Zeit Z bewegt,
- **und wir beobachten** die Nebenwirkung W.

Beispiel, immer noch eine Lehrskizze: wenn wir die Onboarding-Schritte für die zwei wichtigsten Segmente vereinfachen, erwarten wir, dass der Onboarding-Abschluss innerhalb von 14 Tagen steigt, und wir beobachten Support-Tickets auf Verwirrung über die neue Formulierung. Nennen Sie die Schleife in der Aktion. Nach dem Fenster ändern Sie jede Kante, der der Indikator widersprochen hat.

## Schritt 7: Die Annahmen aufschreiben, die falsch sein können

Wählen Sie drei bis fünf unsichere Kanten. Schreiben Sie für jede, was zeigen würde, dass die Kante falsch ist.

- "Wir nehmen an, die Reaktionszeit treibt die Abwanderung stärker als Produktlücken. Wir lägen falsch, wenn die Reaktionszeit sich verbessert, der Abschluss flach bleibt und die Abwanderung sich nicht bewegt."
- "Wir nehmen an, Rabatte erhöhen die Abwanderung über schlechter passende Kundschaft. Wir lägen falsch, wenn diese Kohorten bei gleichem Onboarding ähnlich bleiben wie die anderen."
- "Wir nehmen an, die Komplexität wächst schneller als die Support-Kapazität. Wir lägen falsch, wenn die Tickets pro Konto flach sind."

Schreiben Sie, was die Kante schwächen würde. Können Sie das nicht, behandeln Sie sie als Tatsache, und der nächste Entscheid lernt aus dem Test nichts.

## Fehler, die die zwanzig Minuten verbrauchen

**Die ganze Organisation modellieren.** Halten Sie den Kern klein. Die Nebenliste kann beim nächsten Mal wachsen, nachdem eine Schleife einen Test hat.

**Über die Wahrheit streiten, bevor die Kanten existieren.** Halten Sie die Gegengeschichte als alternative Kante. Testen Sie später. Eine Debatte ohne Pfeile erzeugt keine Karte.

**Verzoegerungen auslassen.** Markieren Sie sie. Sie erklären die meisten Überraschungen im ersten Review.

**Die Karte in der Sitzung lassen.** Buchen Sie ein kurzes Review am Ende des Experimentfensters. Aktualisieren Sie die Kanten, denen der Indikator widersprochen hat.

**Aus dem Hebel einen Backlog machen.** Ein Punkt, eine Verantwortung, ein Fenster. Weitere Aktionen warten auf der Nebenliste.

## Wer warten sollte

Warten Sie, wenn die Lage eine einmalige Wahl ohne Feedback und ohne Chance auf Wiederkehr ist. Eine Schleifenkarte erfindet dann einen Rückweg, den Sie nicht haben. Warten Sie, wenn Sie heute ein kontrolliertes Finanzmodell oder ein Live-Dashboard für den Betrieb als primäres Werkzeug brauchen. Holist-IQ ersetzt die nicht. Nutzen Sie es, wenn der schwere Teil darin besteht, Struktur, Nebenwirkungen und einen Hebelpunkt zu sehen, bevor Sie handeln. Wählen Sie noch zwischen Ansätzen, ist die [Tool-Checkliste](/de/blog/systemdenken-tool-checkliste) die Vergleichsseite.

<div class="blog-faq">
  <h3>Muss ich in zwanzig Minuten fertig sein?</h3>
  <p>Zwanzig Minuten reichen für ein Ergebnis, zwei benannte Schleifen und einen Test. Sind die Kanten dann noch strittig, hören Sie auf und planen einen zweiten Durchgang. Ergänzen Sie in derselben Sitzung keine weiteren Variablen.</p>
</div>

<div class="blog-faq">
  <h3>Was, wenn ich nur eine Schleife finde?</h3>
  <p>Behalten Sie sie, benennen Sie sie und notieren Sie, welcher Typ fehlt. Eine einzelne verstärkende Schleife ohne sichtbaren Ausgleich ist ein Hinweis auf Verzoegerungen oder eine fehlende Variable, keine gescheiterte Karte.</p>
</div>

<div class="blog-faq">
  <h3>Wohin mit den Annahmen?</h3>
  <p>An die Kanten, auf die sie sich beziehen, in Worten, die eine spätere Leserin prüfen kann. Eine Annahme ohne Kante wird nach dem Experiment nicht aktualisiert.</p>
</div>

## Schliessen Sie an einer Karte, die Sie ändern werden

Nutzen Sie dieses Holist-IQ Tutorial einmal an einem lebendigen Ergebnis und wieder, wenn dieses Ergebnis zurückkehrt oder der Test einer Kante widerspricht. Das Produkt verdient die nächste Sitzung, wenn die Karte die Schleifen, die Verzoegerung, den Hebelpunkt und die noch offenen Annahmen noch hält.

Den weiteren Fit, auch wann Sie es auslassen, lesen Sie im [Holist-IQ-Leitfaden](/de/blog/holist-iq).
