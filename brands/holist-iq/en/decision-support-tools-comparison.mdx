Leaders mix **decision support tools** without matching each to the decision clock. Spreadsheets track numbers, dashboards monitor KPIs, causal loop maps expose feedback. Used together they help; used interchangeably they hide loops.

## Spreadsheets: precision without structure

Excel and Google Sheets excel at budgets, scenarios, and shared models. They weakly enforce feedback semantics unless you design loops explicitly. Best for reversible, quantitative slices with clear owners.

## Dashboards: monitoring without adaptation stories

BI dashboards (Looker, Power BI, Tableau) show movement. They rarely show why metrics influence each other. Best when questions are "what moved?" not "what loop dominates?"

## Causal loop and decision map tools

Holist-IQ, kumu, and dedicated CLD platforms foreground loops, polarity, and shared assumptions. Stella-class tools add stocks and equations when quantification is mandatory.

## Whiteboard suites: speed vs semantics

Miro and Lucid speed collaboration. Loop notation stays consistent only with facilitation discipline. Pen-and-paper remains valid for first-hour discovery.

## Honest selection matrix

| Question | Lean toward |
|----------|-------------|
| Recurring metric despite fixes | Causal loop map |
| Monthly budget variance | Spreadsheet |
| Daily operational monitoring | Dashboard |
| Quantified accumulation | Stella/Vensim class |
| Cross-functional alignment on why | Holist-IQ or CLD-first tool |
