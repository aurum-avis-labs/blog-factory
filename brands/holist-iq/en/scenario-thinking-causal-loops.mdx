**Scenario thinking with causal loops** stress-tests one intervention instead of inventing four unrelated futures. You walk the same map with different assumptions on key links.

## Pick one intervention link

Choose a lever the organization can actually pull within a quarter.

## Define two assumption sets

Optimistic and pessimistic polarities or delays on the same link, not entirely different diagrams.

<Image src={img2} alt="Abstract diverging loop paths suggesting scenario branches" width={500} quality={80} class="w-full" />

## Trace metrics on two clocks

Note which variables move in weeks versus quarters. Scenarios fail when everyone watches the slow metric only.

## Decide signals that falsify each scenario

Write what evidence would prove the optimistic path wrong before the deadline.

<Image src={img3} alt="Abstract signal markers on loop paths" width={500} quality={80} class="w-full" />

## When not to scenario-test

Skip when the decision is reversible and cheap, or data cannot support any leading indicator.

## Mid-step: tabletop one lever

Run optimistic/pessimistic stories aloud on a whiteboard map in twenty minutes.
