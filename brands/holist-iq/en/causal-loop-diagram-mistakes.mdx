Pretty maps can still fail decisions. **Causal loop diagram mistakes** usually come from speed: spaghetti links, missing polarity, blame labels, and loops that nobody can trace aloud.

## Mistake 1: Spaghetti without stories

If facilitators cannot read a path in one breath, split variables or remove decorative links.

## Mistake 2: Missing or inconsistent polarity

Every link needs a testable sentence. Inconsistent +/- breaks loop classification.

## Mistake 3: Blame variables

"Bad leadership" is not a factor. Translate into observable pressures: decision latency, goal conflict, information gaps.

## Mistake 4: Too many loops unnamed

Name R1/B1 in plain language. Unnamed loops do not survive email forwards.

## Mistake 5: Ignoring delays

Maps without delays set false expectations on intervention timing.

## Quality bar before publication internally

Two colleagues trace loops independently. If stories diverge, fix structure before sharing upward.

## Mid-step: red pen one existing map

Take yesterday's sketch. Delete three links that lack stories. Add polarity to two orphans.
