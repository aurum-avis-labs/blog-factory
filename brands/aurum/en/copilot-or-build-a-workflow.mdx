Two purchases get mixed: seats for Copilot or ChatGPT Team, and a workflow that assembles itself on Monday. The first is a licence inside existing Microsoft 365 or a company chat. The second is glue between mail, a spreadsheet and a tool.

## When the licence is enough

Drafting, search, a single task in Word, Outlook, Excel, Teams. Someone writes quotes faster. Someone finds last year's spec. The output is different every time. Then you do not need us for a build. Buy the licence, set the data rule ([ChatGPT and customer data](/blog/chatgpt-customer-data-swiss-dsg) in one sentence: no customer file in the Free chat), done.

## When a built workflow fits

Input and output are the same every week. Several systems stick together. The same column, the same recipient, the same approval. The filter is in [which process to automate first](/blog/which-process-to-automate-first).

This is not "Copilot is bad". Copilot does not replace the glue when the figures live in five sources with five permission models.

If the real problem is "the team has no rules", the next step is a workshop, not a flow: [workshop or implementation](/blog/workshop-or-implementation).

## Cost, roughly

A licence is monthly, per seat. A fixed-price package is once, for a bounded build, plus hosting and tokens in production. Figures and package sizes: [what automation costs](/blog/what-automation-costs-switzerland) and the [offer page](/prozess-check). No invented Copilot prices here.

## Unsure which case you are

That is what the [Process Check](/prozess-check) is for. The hour may end with "the licence is enough". Then you have the case in writing and you do not buy a package out of politeness.
