Three tools show up in every other conversation. The order is still: the workflow first, then the tool. The filter is in [which process to automate first](/blog/which-process-to-automate-first). When you should not build at all, and take a Copilot licence instead: [Copilot or build a workflow](/blog/copilot-or-build-a-workflow).

We do not certify a vendor. The landscape you already have decides more than a ranking.

## Three sentences per tool

**Make.** Fast, many connectors, cloud. Good when you need glue in days and a cloud contract plus DPA is acceptable.

**n8n.** Self-hosting is possible, more control over where data sits. More operations on your side: updates, backups, who may touch the workflow.

**Power Automate.** If Microsoft 365 is already the operating system, often the shortest path. A licence and environment topic, not "the newest model".

## Switzerland: data location, not an affiliate list

Personal data: a processing agreement, know where the run lives, no customer files in a private Free chat beside the workflow. Same DPA as the rest of this cluster, not a special statute for n8n.

A tutorial of every connector does not belong here. The Check clarifies the workflow. The tool follows.

## Process first, tool second

The [Process Check](/prozess-check): 60 minutes, a case, which package size. Only then Make, n8n or Power Automate, if a build is needed at all.
