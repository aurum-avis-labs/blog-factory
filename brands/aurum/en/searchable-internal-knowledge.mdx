## Make internal knowledge searchable with AI

<p class="blog-lede">Internal knowledge becomes searchable when a model answers from your files and names a file as proof. Without a citation, you do not use the answer.</p>

You point a model at the files the company already has and ask it to answer from those passages, not from memory. People call that retrieval; the setup is often named RAG. It does not learn the company. If the passage is old, wrong, or visible to the wrong person, the answer is too.

That is a different job from a chat box on the public website: [whether a website chatbot is worth it](/prozess-check/blog/website-chatbot-sme). Which products are allowed in the office is the [allow-list](/prozess-check/blog/approve-ai-tools-allow-list). Connecting a repeatable Microsoft 365 flow is [automating Microsoft 365](/prozess-check/blog/automate-microsoft-365). This page is the files themselves.

## What "answers from your documents" actually does

The model does not contain your handbook. At question time it searches a set of files, pulls relevant passages and writes from them. A good result names the file. You open the file and check the sentence.

Old versions count if they remain in the set and stay open to the person asking. Duplicate handbooks are the usual failure. A rule that lives only in someone's head cannot be retrieved.

## Built-in suite tool or a set you choose

Microsoft and Google search what the signed-in person may already open. A custom set is a smaller pile you choose and keep current. Start with the suite you already pay for, on one question, before you commission a separate search.

Google limits Drive use: if download, copy and print are off, Gemini cannot use the file even when it is shared. PDFs must sit in Drive. Delegated Gmail access does not give Gemini that inbox. Details are on [Google's help page](https://support.google.com/a/users/answer/17010577?hl=en).

A chosen set still needs someone to add new versions and retire old ones. Without an owner, the built-in tool over a tidy folder is the better arrangement. Whether your other software offers an interface for a custom set depends on the files you have. We have not built a ready-made link to bexio, Abacus or a trade-specific program.

## Permissions, and why oversharing becomes an answer

The search does not create a new wall. It reads what this person can already open.

Microsoft says SharePoint sharing is often the most permissive option by default. An "Anyone" link or a company-wide share is material Copilot may use for everyone who can open it. Restricted Content Discovery can keep a high-risk site out of Copilot and organisation-wide search while you review. Permissions stay the same: people who already have the file can still use it. The fix for the wrong audience is the share.

Restricted SharePoint Search is the older site list. Microsoft blocks new enablement from 31 July 2026, does not treat it as a security boundary, and does not change who can open a file. Recently used sites can still appear. Do not treat that switch as cleanup.

On Google: Gemini has the same access as you. A file shared too widely becomes answers for everyone it was shared with. Search follows access. It does not repair it: if the wrong people can open the folder today, they can get answers from it tomorrow.

Before the first pilot, you do not need a week of audit: open the folder you want to answer from and sort by "shared with everyone". Every file there can surface in an answer someone else may see. Move test data and old projects out before the first "how do we do this?" in Teams.

## Clean the files before you switch the search on

Do this for one question, not for the whole archive.

<ol class="blog-steps">
  <li data-step="1"><h3>Name the question</h3><p>One question people already ask, such as the current handover rule or price list.</p></li>
  <li data-step="2"><h3>Name the source</h3><p>The folder or file allowed to answer. If two copies disagree, pick one and say so in the name.</p></li>
  <li data-step="3"><h3>Retire the old copy</h3><p>Move it out or stop the wide link. An archived site in Microsoft 365 cannot be opened until it is brought back, so it drops out of what Copilot can retrieve.</p></li>
  <li data-step="4"><h3>Match the audience</h3><p>People who may read the answer must be able to open the file. Check "Anyone" links and company-wide shares.</p></li>
  <li data-step="5"><h3>Ask once, and open the file</h3><p>Ask the built-in tool. Open every file it cites. If the citation is the old copy, cleanup is not finished.</p></li>
</ol>

Only after that test should you talk about a separate search over a chosen set. If the built-in tool, on a tidy folder, answers with the right file, you do not need another system.

## A made-up example

A made-up example: an office of about 20 people keeps the staff handbook in SharePoint. The current file is "Handbook 2026". A 2022 file remains in the same library, shared with the whole organisation because someone sent a link years ago. A new hire asks Copilot how many weeks of holiday the handbook states. Both files are visible, so either can be retrieved.

Cleanup: move the 2022 file out of the search library or remove the organisation-wide link. Ask the same question again. The citation should be the 2026 file. If not, another copy is still open, often in OneDrive or an attachment saved back to a site.

The same shape applies in Google Drive. Gemini can use the 2022 file for anyone it is shared with. Turning off download, copy and print would also stop Gemini, but that is blunt: people who should read the current file need to open it. Prefer a share that matches the audience.

Nothing in the example is a customer; the holiday number stays blank on purpose. Your handbook and the legal minimum are your own text.

## Who should not start with a search

Do not start if answers were never written down. Write the one-page source first.

Do not start if everything sits in private mailboxes with no shared folder. The suite sees a different pile for each person.

Do not start if the question is a judgement: contract interpretation, dismissal, medical note. Search can surface the document; a person still decides. Do not point internal search at customer messages unless the [allow-list](/prozess-check/blog/approve-ai-tools-allow-list) already permits the tool you chose.

## What it costs

Copilot and Gemini in the suite you already pay for are not a second search budget while you hold the licence. The work is cleanup and an owner for new versions. A custom set outside the suite is often an integration project, not an afternoon.

If staff already paste internal PDFs into free ChatGPT, suite search does not remove that risk by itself. You still need the allow-list and a permitted surface. Search is not a substitute for "may this file go into this tool".
