## Workshop oder Umsetzung: zwei verschiedene Einkäufe

«Wir müssen etwas mit KI machen» vermischt oft zwei Aufträge. Ein KI-Workshop im Unternehmen gibt dem Team eine gemeinsame Sprache, gemeinsame Regeln und ein bis drei Experimente, die es danach selbst fährt. Umsetzung heisst bei uns zuerst der Prozess-Check: ein wiederkehrender Ablauf, ein aufgeschriebener Case, und eine Package-Grösse, wenn Sie ihn danach umsetzen lassen wollen. Beides sind echte Angebote. Sie beantworten verschiedene Jobs.

Für Geschäftsleitung und Büroleitung in einem Schweizer KMU, oft 5 bis 80 Personen, mit wenig oder ohne eigene IT. Sie wählen zwischen einem KI-Workshop und einer Beratung, die in einem umgesetzten Ablauf endet. Sie wählen keinen Prompt-Kurs, und Sie wählen kein Startup-Produkt.

## Wann ein Workshop passt

Der [KI-im-Unternehmen-Workshop](/de/services/ai-in-business) ist für Geschäftsleitung und Fachteams, die Tools schon anfassen oder anfassen sollen, aber nicht dieselben Regeln teilen. Der Auftrag klingt so: alle sollen einen Firmen-Chat oder Copilot nutzen dürfen, ohne Kundendaten in einen privaten Account zu kippen.

Am Ende des Tages sollten drei Dinge auf Papier stehen:

- Welche Tools auf der Positivliste stehen, und welche für Arbeitsdaten draussen bleiben.
- Welche Datenklasse wohin darf: öffentliche Texte, interne Notizen ohne Personen, Personendaten.
- Ein bis drei Experimente, die das Team in den folgenden Wochen selbst fährt, klein genug zum Fertigwerden, mit einer namentlichen Person pro Experiment.

In den Tag bringen Sie die Tools mit, die diese Woche schon offen waren, und zwei oder drei Stellen, an denen Kundentext in einen Prompt ging. Namen können Sie schwärzen. Ein System wird an dem Tag nicht angeschlossen.

So ein Tag passt, wenn das sichtbare Problem die Uneinigkeit ist. Eine Person hat einen privaten ChatGPT-Account. Einer anderen wurde es verboten. Eine dritte fügt Kundenmail ein, «nur um die Antwort zu entwerfen», weil es keinen vereinbarten Ort dafür gibt. Ein Verbot schiebt den Entwurf aufs Handy. Sitze für alle ohne die Seite mit den Regeln lassen dasselbe Loch, jetzt mit einer Rechnung.

Der Workshop passt schlecht, wenn Sie den Ablauf schon kennen und die einzige Frage ist, ob Sie ihn umsetzen lassen. Ein Raum voller Leute baut den Montagsreport bis Feierabend nicht zusammen. Eine Schulung ist keine Verbindung zwischen Posteingang und Buchhaltungstool.

Ein Entwicklungsteam, das Agents im Code nutzen will, ist ein anderes Format: [Agentic Coding](/de/services/agentic-coding). In diesem Text geht es ums Büro, nicht ums Repository.

## Wann der Prozess-Check passt

Der [Prozess-Check](/de/prozess-check) gilt einem wiederkehrenden Ablauf. 30 Minuten online, ein Case (was, wer, wie oft), und eine Package-Grösse, wenn eine Festpreis-Umsetzung der sinnvolle nächste Schritt ist. Die Umsetzung müssen Sie nicht kaufen. Was die halbe Stunde enthält und was sie ablehnt: [was der Prozess-Check ist](/de/prozess-check/blog/was-der-prozess-check-ist).

Bringen Sie Arbeit mit, die schon eine Form hat: Belege, die in die Bücher sollen, Offerten, die in einem Posteingang sterben, ein Report aus mehreren Quellen, eine Tabelle, die nur existiert, weil zwei Systeme nicht miteinander reden. Copilot kann dazwischen trotzdem die richtige Antwort sein. Wann die Lizenz reicht und wann der Übertrag umgesetzt werden muss: [welchen Ablauf Sie zuerst automatisieren](/de/prozess-check/blog/welchen-ablauf-zuerst-automatisieren)

In die halbe Stunde bringen Sie eine Datei vom letzten Durchlauf, den Namen der Person, die das heute macht, und wie oft es vorkommt. Heraus kommt ein Case, oder die Aussage, dass dieser Ablauf noch keiner ist. Das Team auf eine gemeinsame Sprache zu bringen ist in diesen 30 Minuten nicht der Auftrag.

Der Check passt schlecht für «wir brauchen ein gemeinsames Vokabular», «wir brauchen eine Positivliste» oder «der Verwaltungsrat soll sehen, dass wir KI ernst nehmen». Das sind Workshop-Jobs. Er ist auch die falsche halbe Stunde für eine Produktidee oder ein MVP. Eine Produktidee validieren ist ein anderes Angebot. Dieser Cluster schneidet keine Startups.

Ein erfundenes Beispiel, keine Kundenstory: zwölf Personen, eine Buchhaltung, ein gemeinsames Postfach. Am Montag baut jemand den Report neu aus CRM, zwei Tabellen und einem PDF. Am Dienstag fügt eine Kollegin eine Kundenbeschwerde, Name inklusive, in einen privaten Chat, «damit es netter klingt». Der Report ist ein Thema für den Prozess-Check: er wiederholt sich, er hat Inputs, er hat einen Output. Die Beschwerde ist ein Workshop-Thema: das Team hat keine Regel für Personendaten, also landete der Entwurf am falschen Ort. Für die Beschwerde brauchen Sie zuerst die Regel. Den Report vom nächsten Montag liefert der Workshop nicht.

## KI-Schulung und Umsetzung

Gesucht wird das oft als KI-Schulung gegen Umsetzung, oder als KI-Beratung für ein KMU. Schulung, im nützlichen Sinn, ist der Workshop: dieselben Begriffe, dieselbe Positivliste, ein paar Experimente, danach arbeitet das Team. Umsetzung ist eine begrenzte Änderung an einem Ablauf, nachdem dieser Ablauf benannt ist.

Ein Katalog von Tools ist keines von beiden. Eine Prompt-Sammlung, die die Montagsdatei nie berührt, auch nicht. Sagt ein Angebot nicht, welchen der zwei Jobs es fertig macht, können Sie es nicht mit den anderen Offerten im Stapel vergleichen. Bitten Sie den Anbieter, auf das Ergebnis zu zeigen: eine Seite Regeln, die das Büro wirklich benutzt, oder ein Ablauf, der läuft, mit einer Person, die das Resultat prüft. Kommen beide Antworten, fragen Sie nach, für welchen Auftrag das Mandat ist. Beides auf eine Rechnung zu legen ist der Weg, wie Büros einen Tag Folien kaufen und den Report weiter von Hand kopieren.

## Wenn Sie beides brauchen

Manchmal existieren beide Jobs, wie in der Skizze oben. Machen Sie daraus zwei Entscheide, in einer Reihenfolge, nicht ein verwaschenes Projekt.

Beginnen Sie mit dem Workshop, wenn Personendaten die Firma schon in privaten Chats verlassen, oder wenn niemand sagen kann, welches Tool erlaubt ist. Sonst landet der private Chat im neuen Ablauf. Eine Seite Regeln können Sie korrigieren. Ein Package auf dem falschen Datenpfad zahlen Sie als ganze Umsetzung.

Beginnen Sie mit dem Prozess-Check, wenn ein Ablauf schon klar ist, die Daten darin in Ihren bestehenden Tools liegen dürfen, und der Schmerz Stunden, Fehler oder eine einzelne Person ist, die nicht in die Ferien kann. Eine kurze Positivliste können Sie danach schreiben, ohne auf einen ganzen Tag zu warten, wenn nur die Leute beteiligt sind, die diesen Ablauf anfassen.

Kaufen Sie keine Umsetzung, nur damit der Workshop etwas zum Vorzeigen hat. Buchen Sie keinen Workshop, nur damit jemand das Team auf die Umsetzung vorbereitet. Wenn Sie nicht wissen, welcher der beiden Sätze auf Sie zutrifft, lassen Sie beide Rechnungen liegen. Nehmen Sie sich intern eine Stunde: auf die eine Seite die Arbeit, die sich wiederholt, auf die andere die Stellen, an denen Kundendaten heute eingefügt werden. Die längere Spalte ist der erste Einkauf.

## Was Sie nicht kaufen

Eine Produktidee, ein Venture oder ein MVP. Das liegt ausserhalb dieser Wahl.

Ein Rechtsgutachten zum nDSG. Der Workshop kann mit dem Team eine praktische Ampel setzen. Er ersetzt keine Beratung von jemandem, der diese Pflicht für Sie trägt.

Ein Versprechen, dass jeder Sitz bis Freitag «KI nutzt». Ein Workshop kann ändern, was Leute tun dürfen. Eine Umsetzung kann einen Ablauf ändern. Wie viele Personen den Chat öffnen, sagt nichts darüber, ob die Regeln gelten oder der Ablauf läuft.

## Zwei getrennte nächste Schritte

Brauchen Sie Regeln fürs ganze Team, eine Positivliste und ein paar Experimente, die Leute selbst fahren: den Workshop.

Brauchen Sie einen begrenzten Ablauf, der Input und Output schon hat: den Prozess-Check.
