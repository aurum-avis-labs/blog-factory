## Wann KI den Ablauf schlechter macht

Ein Modell mitten im Ablauf macht den Ablauf schlechter, wenn die Daten wandern, die Ausnahmen sich stapeln, niemand den Lauf besitzt, oder Kundenmail und Reportzahlen ohne menschliche Prüfung rausgehen. Der Output sieht fertig aus. Die Stunden steigen. Eine falsche Zahl kommt weiter als ein Entwurf von Hand je kam. Die Person, die den Fehler früher bemerkt hat, steht nicht mehr im Weg.

Für Geschäftsleitung, Betrieb, Finanzen und Büroleitung in einem Schweizer KMU, oft 5 bis 80 Personen, mit wenig oder ohne eigene IT. ChatGPT ist offen, oder eine Copilot-Lizenz liegt da, und jemand will als nächsten Schritt «KI». Legen Sie die Checkliste auf den einen Ablauf, den sie genannt haben, bevor Sie ein Tool oder eine Umsetzung kaufen.

Der Filter für einen Ablauf, den Sie trotzdem versuchen können, steht in [welchen Ablauf zuerst](/de/blog/welchen-ablauf-zuerst-automatisieren). Vier Ja dort (er wiederholt sich, er tut weh, er hat ein Ende, die Datei liegt schon vor) sind der Start. Die Liste hier ist der Stopp. Ein Ja ist ein Grund, innezuhalten. Zwei Ja heisst: Sie würden das Durcheinander automatisieren.

<ul class="blog-checklist">
  <li>Die Quellspalten oder Dateinamen ändern sich, und niemand besitzt die Version, die zählt</li>
  <li>Ein grosser Teil der Läufe braucht eine Sonderregel, die nur eine Person kennt</li>
  <li>Keine einzelne Person darf sagen, der Lauf sei fertig, oder er sei falsch</li>
  <li>Kundenmail oder Zahlen, die in einen Report gehen, gehen raus, ohne dass ein Mensch gelesen hat</li>
</ul>

## Schlechte Daten

Schlechte Daten heisst: der Input ist von Woche zu Woche nicht dasselbe. Die Spalte hiess letzten Freitag «Stunden» und diesen Freitag «Std». Ein Export enthält Gutschriften, der nächste nicht, und niemand hat aufgeschrieben, welche Version der Report benutzt. Die Mappe auf SharePoint und die Mappe auf dem Laptop widersprechen sich, und die Sitzung findet trotzdem statt.

Ein Modell füllt die Lücke. Es liefert eine Summe, die wie die letzte Summe aussieht. Jemand leitet den Absatz intern weiter, weil er sauber klingt. Der Fehler sitzt jetzt in einem zweiten Postfach, im Ton der Firma.

Der [adesso GenAI Impact Report 2026](https://www.adesso.ch/adesso-ch/whitepaper/genai-impact-report-2026-ch.pdf) nennt Datenqualität und fehlende Prozesse als häufigste Hürden in der Schweiz, je mit 32 Prozent, vor dem Modell selbst. Das sind adessos Zahlen, keine eigene Erhebung. Im Büro liegt es an der Datei und daran, dass niemand zuständig ist. Ein anderes Modell trifft dieselbe Datei.

Vor jeder Umsetzung: eine Quelle, stabile Spaltennamen, und eine Person, die eine Datei ablehnen darf, wenn sie in neuer Form ankommt. Gibt es diese Person nicht, ist die Checkliste schon durchgefallen.

## Zu viele Ausnahmen

Jeder zweite Lauf braucht eine Sonderregel. «Diese Kundin ist immer netto 60.» «Diesen Lieferanten im August auslassen.» «Die deutsche Einheit braucht den anderen MWST-Code.» Leben diese Regeln in einem Kopf, wird ein Ablauf, der die Ausnahmen vom letzten Monat festschreibt, zur zweiten Handarbeit. Jemand schaut weiter jeden Lauf an, und obendrein debuggen sie den Ablauf.

Zählen Sie die Ausnahmen der letzten zehn echten Läufe, an den Dateien, nicht aus dem Gedächtnis. Können Sie sie nicht aufschreiben, ist der Prozess nicht stabil genug für ein Tool. Sind es mehr Ausnahmen als Standardläufe, schreiben Sie die Regeln auf und entscheiden Sie, welche von Hand bleiben. Automatisieren können Sie den Pfad, den Sie vor dem Start beschreiben können.

Eine Handvoll bekannter Ausnahmen, mit einer Queue, die ein Mensch abarbeitet, kann eine Umsetzung sein. Eine offene Liste, die jede Woche wächst, ist kein erster Case.

## Niemand zuständig

Jemand muss sagen dürfen, der Lauf sei fertig, und ihn stoppen dürfen, wenn der Output falsch ist. Hängt an diesem Satz kein Name, sitzt die Verantwortung im Chat-Log. Drei Leute sind «irgendwie dran». Ist der Output falsch, kann jede auf das Tool zeigen.

Nennen Sie eine zuständige Person, bevor Sie ein Tool nennen. Sie muss nicht jeden Schritt klicken. Sie muss Start, Ende und Empfänger kennen. Versteht nur eine Person die Logik, wartet das Büro in ihren Ferien. Der Ablauf kommt oft genug, dass das weh tut. Schreiben Sie die Schritte so auf, dass eine zweite Person folgen kann. Ein Skript auf Logik, die in einem Kopf lebt, fällt in der Woche aus, in der diese Person weg ist.

## Ungeprüftes Kundenmail und Reportzahlen

Einen Entwurf intern schreiben lassen ist in Ordnung. Eine Mail an eine Kundin, oder eine Zahl, die in den Montagsreport geht, braucht eine Person, die sie mit der Quelle verglichen hat.

Das ist der Default, wo Personendaten im Text stehen, und wo eine Zahl weiterverwendet wird. Eine falsche Höflichkeitsmail ist peinlich. Eine falsche Summe in einem Kundenstatus, oder in einem Report, den Bank oder Verwaltungsrat sieht, ist die Sorte Fehler, die früher auf einem Bildschirm starb und jetzt in sauberer Schrift das Haus verlässt.

Die Regel ist kurz. Das Modell darf vorbereiten. Eine namentliche Person sendet, oder eine namentliche Person gibt die Datei frei. Können Sie nicht sagen, wer das diesen Monat ist, ist der Ablauf nicht bereit.

## Eine Monatsmail an Eigentümer, die falsch rausging

Stellen Sie sich eine Liegenschaftsverwaltung mit 16 Personen in Winterthur vor. Keine IT-Abteilung. Das ist eine Form, kein Mandat. Jeden Monat schickt die Administration den Eigentümern einen kurzen Status: offene Meldungen, Kosten, was als Nächstes passiert. Die Zahlen kommen aus einer Tabelle, die der Hauswart pflegt. Jemand schlägt vor, ein Modell solle die Mail schreiben, damit die Administration den Nachmittag zurückbekommt.

In einem Monat heisst die Kostenspalte in einer Liegenschaftsdatei CHF, in einer anderen ist sie leer. Eine Meldung wurde vor Ort erledigt und steht in der Tabelle noch offen. Das Modell schreibt eine sichere Summe. Die Administration leitet die Mail weiter, weil sie nach dem Büro klingt. Eine Eigentümerin antwortet wegen einer Belastung, die in der Datei des Hauswarts nie stand.

Der nächste Schritt ist eine Person, die die Spaltennamen besitzt, und eine Regel, dass die Mail wartet, bis jemand die Summe verglichen hat. Eine Umsetzung für die Tabelle selbst wartet, bis diese Spalten einen Monat stillstehen. Sind Tabelle, Spalten und Import schon so stabil, wandert die Frage zu [Excel als Schatten-System](/de/blog/excel-als-schatten-system). Diese Monatsmail war noch nicht dort.

## Wann Sie stoppen, und wann Sie es trotzdem versuchen

Stoppen Sie, wenn das Modell das Urteil erfinden soll: welche Kundin aus einem fairen Grund verärgert ist, welche Ausnahme Sie mit Absicht gewähren, welche Zahl sich für den Verwaltungsrat «richtig anfühlt». Diese Gespräche wechseln jedes Mal. Eine Vorlage kann der Person helfen, die das Gespräch führt. Ein Ablauf, der das Ergebnis verschickt, macht den Prozess schlechter.

Versuchen Sie es, wenn die letzten zehn Läufe gleich aussehen, die Spalten eine zuständige Person haben, die Ausnahmen eine kurze geschriebene Liste sind, und eine namentliche Person den Text an Kundinnen prüft und jede Zahl, die weiterverwendet wird. Dann gilt wieder der Filter in [welchen Ablauf zuerst](/de/blog/welchen-ablauf-zuerst-automatisieren).

Wenn Sie unsicher sind, bringen Sie den Kandidaten in den [Prozess-Check](/de/prozess-check). Die Stunde darf mit «diesen nicht» enden. Das ist ein fertiges Ergebnis. Sechs Wochen an einem Tool, das den chaotischen Ablauf festschreibt, kostet mehr als 60 Minuten Klarheit an der echten Datei.
