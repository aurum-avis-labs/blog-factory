**Importare un file audio su Mac** per ottenerne una trascrizione significa che la registrazione esiste già. Vuoi il riconoscimento vocale su quel file, senza trasformare l’import in un upload per sbaglio. In Vemoir trascini il file nell’app Mac (selettore o drag and drop), lo assegni eventualmente a un progetto e lo fai passare dalla stessa pipeline locale di una riunione registrata dalla barra dei menu. Nel browser puoi fare lo stesso per un clip breve senza inviare il file a Vemoir.

È il percorso dopo la call. Non registra una riunione in diretta e non aggiunge un bot a Zoom o Teams. La prossima call su **questo** Mac si cattura dalla [barra dei menu](/it#capture), non con l’import.

## Cosa puoi importare su un Mac

Vemoir importa file audio locali comuni: **MP3, M4A, WAV, AIFF, CAF e FLAC**. Sono i formati da esportare da un registratore, da una cartella locale dell’app di riunione o da un kit per interviste prima di trascinarli.

Qualche file che la gente prova e che non è in questa lista:

- **Video MP4.** L’elenco di import dell’app Mac è audio. Se Zoom ha lasciato un filmato, cerca `audio_only.m4a` nella stessa cartella datata. Lo strumento browser accetta MP4 (e MP3, M4A, WAV) per un file breve.
- **VTT o TXT.** È già testo. L’import non migliora un file di didascalie.
- **Un link a una registrazione cloud.** L’import ha bisogno di byte sul disco. Scarica l’audio, poi importa. Scaricare una trascrizione cloud non è trascrizione locale; il fornitore ha già fatto il riconoscimento.

I memo vocali iPhone arrivano spesso come M4A dopo AirDrop. Quando il file è locale, è un import ordinario.

Requisiti dell’app Mac: Apple silicon (M1 o più recente), macOS Sonoma 14.2 o successivo, spazio per i modelli. I Mac Intel non sono supportati. La rete serve a setup e download. Poi l’elaborazione può girare offline.

## Importare un file audio su Mac in Vemoir

1. Metti il file sul Mac. Nominalo così da ritrovarlo il mese prossimo. Data e sigla cliente battono `registrazione(3).m4a`.
2. Apri Vemoir. Crea o scegli un **progetto** se la call appartiene a un cliente. Puoi archiviare l’import prima dell’elaborazione, come una registrazione live prima di Record.
3. Usa il selettore, o trascina il file sull’app. Un file diventa un record nella libreria.
4. Lascia finire la trascrizione locale. La trascrizione di riferimento si costruisce dall’audio importato. La separazione speaker gira sul Mac. Poi rinomini. I profili «ricorda questo speaker» sono opt-in e cifrati; le voci sconosciute restano anonime.
5. Modifica verbale, decisioni e azioni sul Mac. Le note digitate confluiscono in quel record. Condividi con le condivisioni native di macOS, solo le parti che scegli.

Nulla di questo elenco carica l’audio su Vemoir. I modelli testo cloud (OpenAI o Anthropic con la tua chiave) sono opt-in per la prosa generata. Non trascrivono il file e l’app non ci cade in silenzio.

Se vuoi una trascrizione senza installare l’app e il clip è breve, vai alla sezione browser. Se il file è una registrazione Zoom locale, la caccia alla cartella è in [trascrivere una registrazione Zoom](/it/blog/trascrivere-registrazione-zoom).

## Import contro registrare la call tu

L’import serve all’audio che esiste già: la registrazione Zoom locale di un collega, un registratore palmare, un’intervista esportata da un altro strumento.

La cattura live serve alla prossima riunione su **questo** Mac: microfono più audio di sistema, nessun bot in lista. L’import non aggiunge audio di sistema che non era nel file. Se l’M4A è già solo microfono, non recuperi il lato remoto importandolo in un’app «migliore».

Non importare un file muto aspettandoti una trascrizione. Se la riproduzione è vuota, il tema successivo è la cattura, non l’import.

## Percorso browser: file brevi, niente installazione

Lo [strumento trascrivere audio](/it/strumenti/trascrivere-audio) gira nella scheda. MP3, M4A, WAV o MP4. **Il file non viene inviato a Vemoir.** Un Whisper pubblico si scarica una volta; le esecuzioni successive possono andare senza rete. Mostra la scheda Rete se qualcuno vuole la prova.

Limiti a settembre 2026:

- **15 minuti** per file
- **3 esecuzioni andate a buon fine a settimana**
- **Niente etichette speaker**
- **Niente registrazione live** nel browser

Dividi un file lungo se resti nella scheda, o usa l’app Mac per l’intera registrazione. Interviste e consenso: [trascrivere un’intervista senza caricarla](/it/blog/trascrivere-intervista-senza-caricarla).

Un file che hai già, senza upload da fornitore? [Apri lo strumento trascrivere audio](/it/strumenti/trascrivere-audio).

## Dopo l’import: cosa puoi condividere

L’export utile di solito è il verbale, le decisioni e le azioni, non l’audio. Tieni o elimina la registrazione secondo la tua scelta di conservazione. Vemoir può rimuovere la cartella audio dopo un passaggio riuscito se hai configurato lo storage così. Il testo può ancora puntare a righe di trascrizione sul Mac.

Non chiamare l’output trascrizione certificata, né certificata GDPR, né privilegiata. Consenso e cancellazione restano tuoi. Se il file importato era la registrazione di qualcun altro, l’import non ripara un consenso mancante.

## Quando un altro percorso è migliore

- **Il file ufficiale deve vivere in Teams o Zoom.** Un download personale non sostituisce la registrazione del tenant.
- **Vi serve oggi una libreria aziendale.** Un file su un Mac non è uno spazio condiviso. Esporta le note.
- **Il file dura 12 minuti e ti serve il testo grezzo una volta.** Meno setup nel browser.
- **Niente Apple silicon.** L’app Mac non gira. Altro strumento per il tuo OS, o il browser per un clip breve.

## Domande frequenti

### Posso importare su Mac un file audio registrato sul telefono?

Sì, una volta che il file è davvero sul Mac (AirDrop, File, USB) e in un formato audio supportato. La registrazione del telefono è solo ciò che ha sentito il microfono del telefono. Una call Zoom su un altro dispositivo non c’è.

### L’import carica la riunione su Vemoir?

No. L’app Mac elabora in locale. Lo strumento browser non invia il file a Vemoir. L’export, o un modello **testo** cloud con la tua chiave, è una scelta successiva, esplicita. La trascrizione dell’audio resta sul dispositivo o nella scheda.

### Quali formati importa Vemoir?

Nell’app Mac: MP3, M4A, WAV, AIFF, CAF e FLAC. Nel browser: MP3, M4A, WAV o MP4, con il tetto di 15 minuti.

### Posso importare mentre una riunione live è ancora in corso?

Un file vecchio, in qualsiasi momento. L’import non cattura la call in diretta. Per la call: barra dei menu, microfono e audio di sistema.

### I file importati hanno etichette speaker?

Nell’app Mac la separazione gira in locale. Rinomini tu; i profili sono opt-in. Il browser non separa nessuno.

### E se la trascrizione importata è nella lingua sbagliata?

La lingua dell’interfaccia (italiano, inglese, tedesco, francese, olandese) è indipendente dal modello vocale. Scegli un modello che copra la lingua parlata. Parakeet v3: 25 lingue europee. Varianti Whisper: copertura propria. Nessuna classifica di accuratezza qui.
