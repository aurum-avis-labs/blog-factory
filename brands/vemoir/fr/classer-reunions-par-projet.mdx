Les **projets de réunion** sont la façon dont Vemoir regroupe appels, notes et suite sur un client ou un dossier. Vous pouvez créer un projet, le nommer, lui donner un client ou un groupe, le décrire et choisir une icône. Depuis la barre de menus, vous sélectionnez ce projet avant d’enregistrer, pour que l’audio y soit classé dès le départ.

Si vous oubliez, la réunion peut encore atterrir dans Enregistrements locaux. Vous pouvez la glisser ensuite dans un projet. Classer d’abord est plus calme, parce que le glossaire et le contexte de ce projet sont ceux en vigueur pendant que le dossier se construit.

## Ce que contiennent les projets de réunion

Un projet tient des réunions groupées par date, les dossiers générés, les actions, les décisions, les documents, les exports et le contexte du projet. Le tableau de bord montre un récapitulatif, le travail ouvert, les décisions récentes, les documents épinglés et les réunions récentes. La recherche dans le projet couvre réunions, transcriptions, artefacts, actions et décisions sur le Mac.


Les actions que vous éditez au niveau projet changent les mêmes enregistrements que ceux de la réunion. Une tâche ne se dédouble pas parce que vous l’avez ouverte depuis la page client. Les nouvelles actions et décisions au niveau projet restent attachées à une réunion source que vous sélectionnez.

Archiver, restaurer et supprimer existent pour les projets et les réunions, avec un nettoyage local. Supprimer un projet retire ses réunions, transcriptions, dossiers générés, actions, décisions, données de locuteurs dans ce périmètre et les dossiers d’enregistrement. C’est une vraie suppression sur ce Mac, pas un masquage. Exportez ce dont vous avez encore besoin avant de confirmer.

## Classer l’appel avant d’enregistrer

1. Créez le projet une fois, avec le nom de client que vous voulez sur le tableau de bord.
2. Ajoutez une courte description si plusieurs projets se ressembleraient autrement.
3. Mettez les termes qui doivent s’écrire d’une certaine façon dans le glossaire de ce projet. Le glossaire n’est pas partagé entre projets.
4. Dans l’enregistreur de la barre de menus, sélectionnez le projet, puis démarrez. Micro et audio système restent les deux pistes locales. Le projet décide seulement où la réunion est classée.
5. Après l’arrêt, ouvrez le tableau de bord du projet si vous voulez le récapitulatif plutôt qu’une seule réunion.


Les fichiers importés peuvent aussi être assignés à un projet, et ils passent par le même pipeline local qu’un appel enregistré. Un fichier n’est pas séparé en micro et audio système s’il ne l’était pas déjà.

## Ce qu’un projet n’est pas

Ce n’est pas un espace de travail collectif. Une autre personne n’obtient pas votre projet en se connectant. Ce n’est pas un dossier cloud. Ce n’est pas un annuaire de locuteurs pour toute l’entreprise. Les profils vocaux, si vous acceptez, restent sur le Mac et se suppriment dans les réglages de confidentialité. Les locuteurs inconnus restent anonymes jusqu’à ce que vous les mémorisiez.

Ce n’est pas non plus un substitut de l’enregistrement officiel du prestataire de réunion. Si le client exige l’archive de Teams ou de Zoom, utilisez aussi leur bouton. Vemoir est votre dossier local, sans bot dans la liste des participants.

Les outils navigateur n’ont pas de projets. [/fr/outils/transcrire-audio](/fr/outils/transcrire-audio) transforme un fichier court en texte après l’appel, jusqu’à 15 minutes, trois passages réussis par semaine, sans étiquettes de locuteurs. Le travail client en cours appartient à l’app Mac.

## Quand laisser les appels non classés est mieux

Les projets de réunion sont le meilleur choix quand vous aurez plus d’un appel avec le même client et que vous voulez glossaire, actions et documents au même endroit. C’est le moins bon choix quand&nbsp;:

- C’est un appel unique que vous exporterez et oublierez. Enregistrements locaux suffisent. Un projet que vous n’ouvrez jamais est du désordre, et un projet que vous supprimez plus tard emporte ses réunions.
- Plusieurs personnes doivent éditer la même liste de tâches dans un navigateur. Un espace cloud qu’elles paient déjà est fait pour cela. Vous pouvez quand même garder l’audio sur le Mac et coller les parties du compte rendu que vous choisissez de partager.
- Vous allez supprimer un projet pour «&nbsp;faire le ménage&nbsp;» et vous n’avez pas exporté les notes. La suppression retire les enregistrements de ce projet. Pausez et exportez d’abord. Notes d’Apple, si vous définissez un dossier, est une destination, décrite à part.

Ask Vemoir peut être limité à une réunion, un projet ou la bibliothèque active. Ouvrir Ask depuis un projet démarre une conversation dans ce périmètre. Les projets archivés sont exclus. C’est utile pour «&nbsp;qu’a décidé ce client&nbsp;», et moins utile si vous vouliez chaque réunion sur le Mac, y compris celles que vous avez archivées.

Réglez le projet dans la barre de menus, puis enregistrez. La forme d’un dossier fini est sous [le compte rendu](/fr#record).

## Une semaine d’appels chez un client

Lundi vous créez «&nbsp;Bise&nbsp;» et posez le nom du client. Vous ajoutez trois termes de glossaire avant le lancement et sélectionnez Bise dans la barre de menus. L’enregistrement s’y classe. Mercredi vous rejoignez depuis une autre app de réunion. Le projet est le même, parce que le classement ne dépend pas de Teams ou de Meet. Vous tapez deux notes manuelles pendant l’appel. Elles restent attachées à cette réunion, avec leur propre provenance, et elles apparaissent quand le tableau de bord liste le travail ouvert.

Vendredi une collègue transmet un vieux M4A. Vous l’importez dans Bise. Ce n’est pas une capture live micro plus système. C’est le fichier, traité en local. Il se place dans la liste par date avec les autres réunions. Ask, ouvert depuis le projet, peut regarder à travers les réunions actives du projet, pas les archivées. Si vous archivez le travail Bise de l’an dernier, ces réunions sortent de ce périmètre. Elles ne sont pas supprimées tant que vous ne les supprimez pas.

Quand le mandat se termine, exportez les notes que vous devez garder, y compris un dossier Notes d’Apple si c’est votre archive, puis supprimez le projet seulement si vous voulez que les réunions locales disparaissent. Le tableau de bord est une vue. Les fichiers sont les réunions. Rien dans le projet n’est envoyé parce que vous lui avez donné un nom de client. Le texte cloud, si vous l’allumez plus tard, est une activation séparée et reste du texte seulement.

## Questions fréquentes

### Puis-je choisir un projet de réunion avant d’enregistrer&nbsp;?

Oui. L’enregistreur de la barre de menus inclut la sélection de projet pour que l’appel soit classé avant le début de la capture.

### Puis-je déplacer une réunion plus tard&nbsp;?

Oui. Vous pouvez glisser des réunions entre Enregistrements locaux et les projets.

### Chaque projet a-t-il son propre glossaire&nbsp;?

Oui. Termes préférés, alias et définitions vivent sur ce projet. La transcription originale reste la preuve.

### Que fait la suppression&nbsp;?

Supprimer un projet retire sur ce Mac ses réunions, transcriptions, dossiers générés, actions, décisions, données de locuteurs dans le périmètre et dossiers d’enregistrement.

### Mes collègues verront-ils le projet&nbsp;?

Non. C’est local. Le partage est une étape séparée, par export ou par le partage macOS des parties que vous choisissez.

### Les actions éditées sur le projet changent-elles la réunion&nbsp;?

Oui. Les éditions au niveau projet mettent à jour les mêmes enregistrements source que ceux affichés dans la réunion.

### Y a-t-il un projet dans les outils navigateur&nbsp;?

Non. Les outils gratuits transcrivent un fichier que vous avez déjà. Ils ne classent pas d’appels en direct sous un client.

### Quel Mac faut-il&nbsp;?

Apple silicon, macOS Sonoma 14.2 ou plus récent, au moins 8 Go de mémoire et 10 Go de stockage libre. 16 Go sont recommandés pour les longues réunions. Les Mac Intel ne sont pas pris en charge.

Créez le client une fois comme projet, sélectionnez-le dans la barre de menus, et enregistrez. Le tableau de bord sous [le compte rendu](/fr#record) est l’endroit où le travail ouvert apparaît ensuite.
