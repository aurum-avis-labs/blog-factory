Masquer un PDF dans le navigateur, quand le fichier est déjà sur votre machine et que vous voulez une copie à envoyer. Déposez-le dans le [masquage PDF](/fr/outils/masquer-pdf), lisez les suggestions, validez ce qui doit disparaître, puis téléchargez un PDF aplati. Le fichier reste dans cet onglet. Un modèle local peut se télécharger une fois pour proposer des données personnelles. Le PDF lui-même n'est pas envoyé.

C'est une aide à la relecture. Ce n'est pas la preuve que chaque détail privé a disparu. Les pages scannées sans couche de texte demandent un rectangle que vous tracez vous-même.

## Masquer un PDF sans l'envoyer

<ol class="blog-steps">
  <li data-step="1"><h3>Déposer le PDF</h3><p>L'analyse démarre seule. Un fichier d'exemple montre d'abord la forme.</p></li>
  <li data-step="2"><h3>Lire la liste</h3><p>Les e-mails et les numéros viennent de motifs. Le reste des données personnelles vient d'un modèle local. Un clic ouvre la page.</p></li>
  <li data-step="3"><h3>Valider ou garder</h3><p>Rien n'est masqué tant que vous ne le validez pas. Tracez un rectangle si le modèle a manqué un logo, une photo ou un scan.</p></li>
  <li data-step="4"><h3>Télécharger</h3><p>Enregistrez le PDF aplati. La page à l'écran reste pour continuer la relecture.</p></li>
</ol>

Le zoom est sur la page. Les commandes de page sont dessous. La liste des suggestions est l'endroit où vous décidez quoi masquer.

Si le PDF est un scan, ou si le texte n'est que dans une image, le modèle n'a rien à lire. Tracez les zones vous-même. Une réunion encore à enregistrer passe par l'app Mac, pas par cette page. Une transcription que vous avez déjà peut devenir des notes sans second envoi : [transcrire un entretien sans envoi](/fr/blog/transcrire-entretien-sans-envoi).

## Avant d'envoyer le fichier

Ouvrez le téléchargement et regardez chaque page, pas seulement la première. Un bandeau doit couvrir tout le signe, y compris les lettres qui descendent sous la ligne. Si un coin de mot reste visible, marquez la zone et exportez encore.
