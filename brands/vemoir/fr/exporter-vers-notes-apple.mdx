**Exporter vers Notes** envoie un compte rendu de réunion dans un compte et un dossier Notes que vous choisissez. Vemoir conserve l’identifiant de la note. L’export suivant met à jour cette note au lieu de laisser une seconde copie à côté. Vous voyez toujours un aperçu de la note combinée avant la remise.

L’audio ne part pas avec la note. Vous exportez le compte rendu : les sections de texte que vous avez sélectionnées.

## Ce que l’export met dans la note

La note contient le résumé de référence, les points clés, les risques, les questions ouvertes, les décisions, les actions, les participants, les documents personnalisés et la provenance Vemoir. Les blocs dérivés qui ne répètent que le résumé sont omis. Les notes tapées pendant la réunion restent votre texte. Elles ne sont pas collées comme citations de transcription.

Si vous classez les réunions sous un projet client, c’est là que se règle la destination Notes. Pour classer avant d’enregistrer, voir [projets de réunion](/fr/blog/classer-reunions-par-projet).

Un export automatique facultatif tourne après le succès du traitement. Laissez-le éteint si vous voulez l’aperçu à chaque fois. Automatique envoie toujours du texte seulement, pas l’audio.

Vous voulez le dossier fixé avant l’appel ? Classez la réunion dans un [projet](/fr/blog/classer-reunions-par-projet) et réglez le chemin Notes là.

## Ce qui reste sur le Mac

Transcription, séparation des locuteurs et enregistrement restent sur le Mac. Notes reçoit le texte exporté via la destination choisie. Une clé API personnelle pour le texte généré est distincte : texte seulement, Trousseau, activation explicite. Elle ne remplace pas Notes et n’envoie pas d’audio. Un export Notes en échec ne bascule pas vers un autre carnet cloud.

Supprimer la réunion ou purger l’audio dans Vemoir ne retire pas une note déjà envoyée. La supprimer dans Notes est un acte séparé. Une mise à jour depuis Vemoir écrase le contenu géré par Vemoir dans cette note. Lisez l’aperçu quand le procès-verbal a beaucoup changé.

Les réglages d’identité peuvent faire correspondre `ME` à votre nom et afficher `Name (Me)` dans le contenu copié ou partagé. Réglez cela avant un export client si « ME » paraît inachevé.

Les noms de locuteurs dans la note correspondent à ceux du compte rendu au moment de l’export. Renommez les groupes anonymes sans créer de profil vocal, puis exportez à nouveau. Un profil chiffré via `Remember this speaker` n’entre pas dans le corps de la note.

## iCloud, autorisations, mauvais compte

Les notes se synchronisent via iCloud sur le compte sélectionné. Vemoir écrit la note sur ce Mac ; Apple gère la synchronisation vers vos autres appareils. Si la note manque sur un téléphone, vérifiez que le même compte iCloud est actif dans Notes.

macOS peut demander si Vemoir peut écrire dans Notes. Cette invite concerne la note, pas la capture d’écran. L’audio système des réunions passe par l’autorisation d’enregistrement d’écran lors de la capture.

Si la note atterrit dans le mauvais compte Notes, éteignez l’export automatique, choisissez à nouveau le compte et exportez une fois à la main. L’identifiant stocké appartient à la note du dernier passage réussi. Changer de compte sans nouvel export ne déplace pas l’ancienne note.

## Quand Notes est la mauvaise destination

Exporter vers Notes convient si vous travaillez déjà dans Notes, voulez une note par réunion à jour et choisissez le dossier vous-même. Évitez-le si :

- Le client exige un PDF dans sa data room ou sur un disque partagé avec une convention de nommage. Copiez le texte au format demandé. Ce chemin ne produit pas de PDF ni de Word.
- Plusieurs personnes doivent coéditer un document vivant avec commentaires. Le partage suit ensuite les règles d’Apple. Vemoir n’ajoute pas d’espace d’équipe.
- Vous voulez l’enregistrement dans la note. L’export est le compte rendu, pas les fichiers audio.
- Les noms de locuteurs ou le [glossaire projet](/fr/blog/glossaire-projet-reunion) sont encore faux. Corrigez, régénérez si besoin, puis exportez.

Copier dans le presse-papiers reste pour résumé, document ou procès-verbal sans Notes. Le partage de la barre suit la vue : résumé, actions, décisions ou transcription.

Le sélecteur de dossier et l’état d’export sont sous [les exports](/fr#exports).

## Exports du projet ou actions de réunion

Vous pouvez exporter depuis les actions d’une réunion ou depuis les exports du projet pour les réunions liées à ce mandat. Les deux chemins utilisent l’identifiant de note stocké par réunion, pas une note unique pour tout le client. Pour une note fraîche à chaque appel hebdomadaire, exportez chaque réunion séparément. Pour une note vivante par réunion, réexportez la même réunion après avoir corrigé le compte rendu.

Les documents personnalisés générés dans Vemoir peuvent apparaître dans l’aperçu si vous les incluez. Ils ne remplacent pas la transcription. Corrigez l’identité si un document affiche encore « ME » avant l’export.

## Après régénération, exporter à nouveau

Vous corrigez une étiquette et une entrée de glossaire, puis régénérez le procès-verbal. La note d’hier garde les anciens noms jusqu’à un nouvel export. La mise à jour réutilise l’identifiant stocké, pour que Notes n’ajoute pas une seconde page au titre presque identique. Annulez depuis l’aperçu si quelque chose cloche ; l’ancienne note reste jusqu’à une remise réussie.

Avec l’export automatique allumé, un traitement réussi tente la mise à jour sans clic de plus. Éteignez-le pour un client sensible si vous voulez relire chaque aperçu. Les erreurs ne partent pas vers l’e-mail, un autre compte Notes ou un prestataire cloud.

## Questions fréquentes

### Un second export crée-t-il une seconde note Notes ?

Non. Vemoir stocke l’identifiant et met à jour cette note. L’aperçu montre la note combinée avant la remise.

### Puis-je choisir le dossier ?

Oui. Un projet peut sélectionner un vrai compte Notes et un dossier imbriqué.

### L’export peut-il tourner tout seul ?

Vous exportez à la main depuis les actions de réunion ou les exports du projet, ou vous activez l’export automatique après un traitement réussi.

### La note inclut-elle l’audio ?

Non. Elle inclut le compte rendu écrit : résumé, points clés, risques, questions ouvertes, décisions, actions, participants, documents personnalisés et provenance.

### Que se passe-t-il si la mise à jour échoue ?

L’état de nouvelle tentative et les erreurs restent visibles. Vérifiez le compte Notes et relancez quand la réunion est en bon état.

### Les locuteurs inconnus seront-ils nommés dans la note ?

Seulement si vous les avez nommés. Les inconnus restent anonymes tant que vous n’avez pas posé une étiquette ou accepté de mémoriser une voix.

### Est-ce la même chose que les outils navigateur gratuits ?

Non. Ces outils transcrivent un fichier dans le navigateur, jusqu’à 15 minutes, sans remise vers Notes et sans noms de locuteurs. L’export Notes est dans l’app Mac.

### Faut-il un bot dans la réunion pour cela ?

Non. Vous enregistrez sur le Mac, puis exportez le texte voulu. Personne n’a été ajouté à l’appel.

### Faut-il un compte iCloud pour voir la note sur l’iPhone ?

Seulement si vous voulez la même note sur plusieurs appareils Apple. Vemoir écrit sur le Mac. La synchronisation entre l’iPhone et le Mac passe par iCloud, selon les réglages de votre compte Notes.

Choisissez le dossier une fois, exportez quand le procès-verbal est juste, et laissez l’export suivant rafraîchir cette note. Les commandes sont sous [les exports](/fr#exports).
