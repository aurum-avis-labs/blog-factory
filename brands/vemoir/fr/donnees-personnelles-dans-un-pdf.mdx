Des données personnelles encore dans un PDF passent inaperçues parce que la page a l'air finie. La couche de texte peut encore porter un nom, un lieu, une date de naissance, un e-mail ou un numéro qui identifie quelqu'un, même si vous ne vouliez partager que l'argument.

L'envoi est le moment qui compte. Qui ouvre le fichier peut sélectionner le texte, le copier et le chercher. Un surlignage noir dans un traitement de texte n'enlève pas le texte.

## Ce qui reste souvent dans le fichier

Un CV, une lettre médicale, une facture et une note de projet échouent aux mêmes endroits. Le nom est dans le titre. La ville est à côté d'un code de région. La date de naissance est écrite en toutes lettres, pas seulement en chiffres. L'e-mail et le téléphone sont dans une phrase ordinaire. Un identifiant se cache dans une ligne qui ressemble à de l'administration.

Un titre de poste, un nom de produit et le propos du document ne sont pas, à eux seuls, des données personnelles. Le risque est le détail qui désigne une personne.

Un scan d'une page papier est différent. Sans couche de texte, la sélection ne fait rien, et l'image montre quand même le détail. Vous couvrez l'image, ou vous ne partagez pas cette page.

## Lire une page avant de l'envoyer

  <li data-step="2"><h3>Lire les bords</h3><p>En-tête, pied et signature sont l'endroit où les noms et les numéros restent.</p></li>

## Questions

### Si je peux sélectionner les mots, sont-ils dans le fichier ?
Oui. Un surlignage noir dans un traitement de texte ne les enlève pas.

### Un titre de poste est-il une donnée personnelle ?
Pas à lui seul. Le risque est un détail qui désigne une personne.

### Et une page scannée ?
Il n'y a pas de texte à sélectionner. Couvrez l'image, ou ne partagez pas cette page.
