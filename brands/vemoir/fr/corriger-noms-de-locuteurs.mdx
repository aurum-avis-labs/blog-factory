Vous pouvez **corriger les noms de locuteurs** d'une réunion Vemoir terminée en renommant l'étiquette. Ce renommage ne crée pas de profil vocal. `Remember this speaker` est un autre contrôle, et il attend un oui explicite. Si le seul problème est un nom sur cette transcription, changez l'étiquette et arrêtez-vous là.

La séparation brute et les lignes horodatées restent la preuve. Vous corrigez à qui le groupe se rapporte, pas les mots.

## Corriger les noms de locuteurs une fois la transcription écrite

Les étiquettes apparaissent après l'arrêt, quand la séparation sur le Mac a groupé l'audio. Jusque-là, un aperçu live n'est qu'un aperçu. Ne passez pas ce temps à nommer des gens dans l'aperçu en attendant que ce brouillon soit le compte rendu.


Ouvrez la réunion, passez à la transcription ou à la liste des locuteurs, et lisez quelques tours avant de renommer. Un mauvais nom est souvent l'une de ces trois choses&nbsp;: le groupe est juste et l'étiquette est un placeholder, deux personnes ont été groupées, ou votre voix et la pièce ont fui dans le même micro. Le renommage règle le premier cas. Les deux autres demandent une correction du groupe, pas un nom assuré sur un mélange.

## Renommer sans enregistrer une voix

1. Ouvrez la réunion terminée.
2. Sélectionnez l'étiquette fausse.
3. Tapez le nom voulu sur ce compte rendu. Laissez `Remember this speaker` tranquille.
4. Vérifiez une ligne horodatée pour voir le nouveau nom sur les bons tours.
5. Si vous avez mémorisé quelqu'un par erreur, refusez ou annulez cette correspondance, puis supprimez ou anonymisez le profil dans les réglages de confidentialité. Le renommage lui-même n'était pas le problème.


Les locuteurs inconnus restent anonymes jusqu'à ce que vous les nommiez. Une étiquette vide ou générique est honnête quand vous n'êtes pas sûr. Inventer un nom pour ranger le compte rendu est pire que «&nbsp;Locuteur 2&nbsp;» si vous ne défendriez pas ce nom plus tard.

Corriger et annuler conservent la séparation sous-jacente. Si un résumé régénéré a été écrit avec l'ancien nom, régénérez après le renommage pour que actions et décisions prennent l'étiquette. Vos notes manuelles gardent leur provenance. Elles ne sont pas réécrites en silence comme si la transcription avait toujours dit le nouveau nom.

## Quand un profil, ou aucun nom, est meilleur

Un renommage sans profil est le meilleur choix pour un appel unique, un invité, ou toute personne que vous ne voulez pas stocker comme modèle vocal. Créer un profil n'est meilleur que si cette personne reviendra et que vous voulez une suggestion plus tard, avec des barrières de confiance. Ce choix est décrit dans [profils de locuteurs sur Mac](/fr/blog/profils-locuteurs-sur-mac).

Laisser l'étiquette anonyme est meilleur quand vous ne distinguez pas les voix. Un preneur de notes cloud partagé peut être meilleur quand toute l'équipe a besoin du même annuaire et que votre politique accepte leur cloud. Vemoir ne synchronise pas un roster de locuteurs vers d'autres Mac. Les noms que vous tapez restent dans le dossier local.

Les outils du navigateur n'aident pas ici. [/fr/outils/transcrire-audio](/fr/outils/transcrire-audio) transforme un fichier que vous avez déjà en texte, jusqu'à 15 minutes, et il n'invente pas de noms. Si le fichier n'a pas d'étiquettes, la page le dit. La séparation live est l'app Mac.

## Les noms dans le compte rendu et dans ce que vous partagez

Les comptes rendus, actions et décisions générés peuvent montrer les noms que vous avez posés. L'export et la copie utilisent ces noms. Un réglage d'identité séparé peut mapper `ME` vers votre vrai nom et l'afficher comme `Name (Me)` dans le texte copié ou partagé. C'est vous, pas un profil d'invité.

Apple Notes et les autres exports portent le dossier que vous avez choisi d'envoyer. Ils n'attachent pas le modèle vocal chiffré. Si un nom est sensible, corrigez-le avant d'exporter. Le partage est un geste conscient depuis la réunion, pas une publication automatique vers une équipe.

Un glossaire peut stabiliser les mots produit. Il n'assigne pas les personnes. Si «&nbsp;Alex&nbsp;» est à la fois un produit et une personne, le renommage marque la personne. Le glossaire marque le produit.

L'audio ne quitte pas le Mac pour cette modification. Une clé API texte seulement, si vous en avez activé une, ne reçoit toujours pas l'enregistrement parce qu'un nom était faux.

Le lieu de travail est la réunion que vous venez d'arrêter, depuis [capture](/fr#capture) et la bibliothèque.

## Un appel à quatre personnes

La transcription montre Locuteur 1, Locuteur 2, Locuteur 3, et un groupe qui mélange clairement deux voix. Vous renommez Locuteur 1 et Locuteur 2 parce que vous entendez qui ils sont sur des tours consécutifs. Vous laissez Locuteur 3 comme nom provisoire jusqu'à vérification contre l'enregistrement, si vous avez gardé l'audio. Vous ne renommez pas le groupe mélangé au nom de la personne la plus forte pour ensuite le mémoriser. Dans le compte rendu, vous pouvez dire dans vos propres notes que le dernier point était disputé entre deux personnes. Ces notes ont une provenance distincte de la transcription.

Après les renommages, jetez un œil aux actions. Si un responsable a été généré comme Locuteur 1, régénérez ou éditez le responsable pour que la tâche porte le nom que vous venez de poser. Éditer l'action à la main suffit quand le seul changement est la personne. La régénération est meilleure quand plusieurs lignes générées disent encore le placeholder.

Puis exportez, ou non. Un mauvais nom qui ne quitte pas le Mac est un problème plus petit qu'un mauvais nom collé dans un e-mail client. Corrigez l'étiquette d'abord. Le bouton de partage est une étape ultérieure, depuis le résumé, les actions, les décisions ou la transcription, selon la vue.

## Questions fréquentes

### Corriger un nom de locuteur enregistre-t-il sa voix&nbsp;?

Non. Un renommage change l'étiquette de cette réunion. Un profil vocal n'est créé que si vous choisissez `Remember this speaker`.

### Puis-je corriger les noms pendant l'appel&nbsp;?

Vous pouvez regarder un aperçu, mais la transcription qui compte est construite après l'arrêt, à partir de l'audio finalisé. Renommez sur cette transcription terminée.

### Et si deux personnes partagent une étiquette&nbsp;?

Ne donnez pas à ce groupe un seul nom assuré pour ensuite le mémoriser. Corrigez le groupement si les contrôles permettent de le séparer ou de le refuser, ou laissez-le sans nom et notez l'ambiguïté dans vos notes.

### Le résumé gardera-t-il l'ancien nom&nbsp;?

Régénérez après le renommage pour que les lignes générées prennent la nouvelle étiquette. Le texte que vous avez tapé vous-même reste le vôtre.

### Puis-je annuler un mauvais renommage&nbsp;?

Oui. Corriger et annuler conservent la séparation brute et les preuves horodatées. Si un profil a aussi été créé, retirez-le dans les réglages de confidentialité.

### Les exports incluent-ils le profil vocal&nbsp;?

Non. Le partage et l'export envoient le dossier que vous choisissez, par exemple le résumé et le texte de la transcription. Les embeddings de profil restent hors des exports.

### Et s'il n'y a aucune étiquette&nbsp;?

Alors la séparation n'a pas produit de groupes que vous pouvez nommer, ou vous êtes dans un outil navigateur qui ne nomme jamais les locuteurs. L'app Mac est le chemin avec séparation. Un fichier sans marques de locuteur ne les gagne pas via un nettoyeur de texte.

### Est-ce un conseil juridique sur les noms dans un compte rendu&nbsp;?

Non. Mettre un nom sur une ligne est votre choix éditorial. Enregistrer demande toujours le consentement que votre situation exige.

Renommez l'étiquette, sautez Remember, et vérifiez un horodatage avant d'exporter. La liste des locuteurs fait partie de [capture](/fr#capture).
