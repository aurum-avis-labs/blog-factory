Vous **corrigez les noms de locuteurs** d'une réunion Vemoir terminée en renommant l'étiquette dans la transcription. Ce renommage ne crée pas de profil vocal. `Remember this speaker` est un autre contrôle, et il attend un oui explicite. Si le seul problème est un nom sur ce compte rendu, changez l'étiquette et arrêtez-vous là.

La séparation brute et les lignes horodatées restent la preuve. Vous corrigez à qui le groupe se rapporte, pas les mots prononcés.

## Corriger les noms de locuteurs une fois la transcription écrite

Les étiquettes apparaissent après l'arrêt, quand la séparation sur le Mac a groupé l'audio. Jusque-là, un aperçu live n'est qu'un aperçu. Ne perdez pas ce temps à nommer des gens dans l'aperçu: ce brouillon ne sera pas le compte rendu.

Ouvrez la réunion, passez à la transcription ou à la liste des locuteurs, et lisez quelques tours avant de renommer. Un mauvais nom est souvent l'une de ces trois choses&nbsp;: le groupe est juste et l'étiquette est un placeholder, deux personnes ont été groupées, ou votre voix et le bruit de la pièce sont passés par le même micro. Le renommage règle le premier cas. Les deux autres demandent une correction du groupe, pas un nom assuré sur un mélange. S'il n'y a aucune étiquette, commencez par [locuteurs manquants dans une transcription](/fr/blog/locuteurs-manquants-transcription) avant de supposer qu'un renommage suffit.

Les profils servent quand quelqu'un revient souvent. Le parcours complet est dans [profils de locuteurs sur Mac](/fr/blog/profils-locuteurs-sur-mac). Ce texte vise le cas où vous voulez seulement le bon nom sur le compte rendu du jour.

## Renommer sans enregistrer une voix

1. Ouvrez la réunion terminée.
2. Sélectionnez l'étiquette fausse.
3. Tapez le nom voulu sur ce compte rendu. Laissez `Remember this speaker` tranquille.
4. Vérifiez une ligne horodatée pour voir le nouveau nom sur les bons tours.
5. Si vous avez mémorisé quelqu'un par erreur, refusez ou annulez cette correspondance, puis supprimez ou anonymisez le profil dans les réglages de confidentialité. Le renommage lui-même n'était pas le problème.

Les locuteurs inconnus restent anonymes jusqu'à ce que vous les nommiez. Une étiquette vide ou générique est honnête quand vous n'êtes pas sûr. Inventer un nom pour ranger le compte rendu est pire que «&nbsp;Locuteur 2&nbsp;» si vous ne pouvez pas défendre ce nom plus tard.

Corriger et annuler conservent la séparation sous-jacente. Si un résumé régénéré montre encore l'ancien nom, régénérez après le renommage pour que actions et décisions prennent l'étiquette. Vos notes manuelles gardent leur provenance. Elles ne sont pas réécrites en silence comme si la transcription avait toujours dit le nouveau nom.

## Quand un profil, ou aucun nom, est meilleur

Un renommage sans profil convient à un appel unique, un invité, ou toute personne que vous ne voulez pas stocker comme modèle vocal. Laisser l'étiquette anonyme est meilleur quand vous ne distinguez pas les voix. Un preneur de notes cloud partagé peut convenir quand toute l'équipe a besoin du même annuaire et que votre politique accepte leur cloud. Vemoir ne synchronise pas de liste de locuteurs vers d'autres Mac. Les noms que vous tapez restent dans le compte rendu local.

Les outils du navigateur n'aident pas ici. [Transcrire audio](/fr/outils/transcrire-audio) transforme un fichier que vous avez déjà en texte, jusqu'à 15 minutes, et il n'invente pas de noms. La séparation live est l'app Mac.

## Les noms dans le compte rendu et dans ce que vous partagez

Les comptes rendus, actions et décisions générés peuvent montrer les noms que vous avez posés. L'export et la copie utilisent ces noms. Un réglage d'identité séparé peut mapper `ME` vers votre vrai nom et l'afficher comme `Name (Me)` dans le texte copié ou partagé. C'est vous, pas un profil d'invité.

Apple Notes et les autres exports portent le compte rendu que vous avez choisi d'envoyer. Ils n'attachent pas le modèle vocal chiffré. Si un nom est sensible, corrigez-le avant d'exporter. Le partage est un geste conscient depuis la réunion, pas une publication automatique vers une équipe.

Un glossaire peut stabiliser les mots produit. Il n'assigne pas les personnes. Si «&nbsp;Alex&nbsp;» est à la fois un produit et une personne, le renommage marque la personne. Le glossaire marque le produit.

L'audio ne quitte pas le Mac pour cette modification. Une clé API texte seulement, si vous en avez activé une, ne reçoit toujours pas l'enregistrement parce qu'un nom était faux.

Pour la prochaine réunion, Vemoir enregistre depuis la barre de menus et sépare les locuteurs sur le Mac. Voir [capture](/fr#capture) et la bibliothèque.

## Un appel à quatre personnes

La transcription montre Locuteur 1, Locuteur 2, Locuteur 3, et un groupe qui mélange clairement deux voix. Vous renommez Locuteur 1 et Locuteur 2 parce que vous entendez qui ils sont sur des tours consécutifs. Vous laissez Locuteur 3 comme nom provisoire jusqu'à vérification contre l'enregistrement, si vous avez gardé l'audio. Vous ne renommez pas le groupe mélangé au nom de la personne qui parle le plus fort pour ensuite le mémoriser. Dans vos notes manuelles vous pouvez dire que le dernier point était disputé entre deux personnes. Ces notes ont une provenance distincte de la transcription.

Après les renommages, jetez un œil aux actions. Si un responsable a été généré comme Locuteur 1, régénérez ou éditez le responsable pour que la tâche porte le nom que vous venez de poser. Éditer l'action à la main suffit quand le seul changement est la personne. La régénération est meilleure quand plusieurs lignes générées disent encore le placeholder.

Vérifiez une ligne de décision et une action. Si les deux portent le nouveau nom, la correction est bouclée. Si seule la transcription a le nom et l'action dit encore «&nbsp;Locuteur 2&nbsp;», la réunion n'est pas prête à transférer. Cela arrive si vous avez renommé sans régénérer ni éditer l'action. Les deux corrections prennent moins de temps qu'une nouvelle prise.

Puis exportez, ou non. Un mauvais nom qui ne quitte pas le Mac est un problème plus petit qu'un mauvais nom collé dans un e-mail client. Corrigez l'étiquette d'abord. Le bouton de partage est une étape ultérieure, depuis le résumé, les actions, les décisions ou la transcription, selon la vue.

## Questions fréquentes

### Corriger un nom de locuteur enregistre-t-il sa voix&nbsp;?

Non. Un renommage change l'étiquette de cette réunion. Un profil vocal n'est créé que si vous choisissez `Remember this speaker`.

### Puis-je corriger les noms pendant l'appel&nbsp;?

Vous pouvez regarder un aperçu, mais la transcription qui compte est construite après l'arrêt, à partir de l'audio finalisé. Renommez sur cette transcription terminée.

### Et si deux personnes partagent une étiquette&nbsp;?

Ne donnez pas à ce groupe un seul nom assuré pour ensuite le mémoriser. Corrigez le groupement si les contrôles permettent de le séparer ou de le refuser, ou laissez-le sans nom et notez l'ambiguïté dans vos notes.

### Le résumé gardera-t-il l'ancien nom&nbsp;?

Régénérez après le renommage pour que les lignes générées prennent la nouvelle étiquette. Le texte que vous avez tapé vous-même reste le vôtre.

### Puis-je annuler un mauvais renommage&nbsp;?

Oui. Corriger et annuler conservent la séparation brute et les preuves horodatées. Si un profil a aussi été créé, retirez-le dans les réglages de confidentialité.

### Les exports incluent-ils le profil vocal&nbsp;?

Non. Le partage et l'export envoient le compte rendu que vous choisissez, par exemple le résumé et le texte de la transcription. Les données vocales du profil restent hors des exports.

### Et s'il n'y a aucune étiquette&nbsp;?

Alors la séparation n'a pas produit de groupes que vous pouvez nommer, ou vous êtes dans un outil navigateur qui ne nomme jamais les locuteurs. L'app Mac est le chemin avec séparation.

### Le glossaire corrige-t-il les noms de locuteurs&nbsp;?

Non. Il oriente l'orthographe du texte généré. Les noms viennent des étiquettes ou des profils confirmés.

### Est-ce un conseil juridique sur les noms dans un compte rendu&nbsp;?

Non. Mettre un nom sur une ligne est votre choix éditorial. Enregistrer demande toujours le consentement que votre situation exige.

Renommez l'étiquette, sautez Remember, et vérifiez un horodatage avant d'exporter. La liste des locuteurs fait partie de [capture](/fr#capture).
