Une **relance à partir des notes de réunion** est le message ou le fichier que vous envoyez après l’appel, construit depuis le compte rendu et non depuis la mémoire. Il dit ce qui a été choisi, qui fait la suite et ce qui reste ouvert. N’y joignez l’enregistrement que si l’autre personne a demandé la bande.

C’est un travail d’écriture avec une limite nette. Les notes restent comme preuve sur votre Mac. La relance est le document court qui quitte la salle.

## Ce qu’une relance à partir des notes de réunion contient

Quatre blocs suffisent pour la plupart des appels :


<Image src={inline1} alt="Lettre de suivi et carnet ferme" width={700} quality={80} class="w-full" />

<p><em>Photo by <a href="https://unsplash.com/@brandomakesbranding?utm_source=blog_factory&utm_medium=referral" target="_blank" rel="noopener noreferrer">brandomakesbranding</a> on <a href="https://unsplash.com/?utm_source=blog_factory&utm_medium=referral" target="_blank" rel="noopener noreferrer">Unsplash</a></em></p>

1. **Une phrase sur la raison de l’appel.** Pas un résumé des politesses.
2. **Décisions.** Formulation, personne, date. Si rien n’a été décidé, dites-le.
3. **Actions.** Description, responsable, échéance. Sans responsable, la ligne est un souhait.
4. **Questions ouvertes.** Ce qu’il vous manque encore, et de qui.

Une relance client peut finir sur la prochaine date. Une relance interne peut finir sur l’endroit où vit le compte rendu complet. Aucune des deux n’a besoin de la transcription collée dessous.

Un canevas pour Mail ou Notes :

```text
Objet : {réunion}, {date}

Merci pour le temps du {date}.

Décisions
-

Actions
- {quoi}. Responsable : {nom}. Échéance : {date}.

Encore ouvert
-

Suite
-
```

## L’écrire le jour même

La relance se dégrade dans la nuit, parce que vous commencez à lisser. Écrivez depuis les notes, pas depuis l’humeur de l’appel.

Un ordre qui tient :

1. Arrêtez l’enregistrement et laissez le compte rendu se terminer. Un aperçu en direct pendant l’appel n’est qu’un aperçu. La transcription qui compte est celle bâtie sur l’audio fini.
2. Relisez décisions et actions. Corrigez un mauvais responsable avant de copier quoi que ce soit.
3. Reprenez les notes saisies pendant l’appel (un chiffre, un nom, une contrainte). Ces notes sont les vôtres. Elles doivent apparaître comme telles, pas comme une citation.
4. Copiez la version courte. Envoyez-la. Laissez la transcription brute sur le Mac.

Si vous utilisez votre propre clé OpenAI ou Anthropic pour le brouillon, ce chemin est uniquement du texte, et vous l’activez vous-même. L’audio ne fait pas partie de la requête. Si le fournisseur échoue, le brouillon s’arrête. Vous pouvez quand même copier ce qui est déjà sur la séance.

## Copier, un document ou Notes

Vemoir offre trois sorties. Toutes restent sur le Mac jusqu’à ce que vous les envoyiez.

**Presse-papiers.** Résumés, documents et procès-verbaux se copient. La barre d’outils suit la section affichée : résumé, actions, décisions ou transcription. Copiez décisions et actions pour la relance. Ne copiez la transcription que si quelqu’un a demandé les mots.

**Un document.** La zone Documents écrit un fichier Markdown pour une séance ou un projet, à partir d’un modèle intégré ou d’un modèle à vous. Il s’enregistre tout seul, garde une provenance et peut être régénéré sans jeter vos modifications. Vous pouvez enregistrer une réponse Ask comme document dans cette séance ou ce projet. L’export peut sortir sans les liens de preuve, ce que vous voulez dans une note lue sans ouvrir votre bibliothèque.

**Notes Apple.** Choisissez un compte réel et un dossier sur le projet. Exportez depuis la séance, ou activez l’export après un traitement réussi. La note comprend le résumé, les points clés, les risques, les questions ouvertes, les décisions, les actions, les participants et les documents personnalisés, plus une ligne de provenance. Vemoir garde l’identifiant de la note pour qu’un export ultérieur mette à jour la même note au lieu d’en créer une seconde. Prévisualisez la note combinée avant le passage.

Il n’y a pas d’export PDF ou DOCX dans l’app. Si un portail client en exige un, collez le Markdown ou le texte de Notes dans l’outil qu’ils utilisent déjà. Le contenu est la relance. Le contenant est le leur.

Le partage passe par les mêmes sections, via la feuille de partage de macOS, pour la partie que vous choisissez. Vous n’avez pas à partager l’enregistrement pour partager la note.

Si vous associez `ME` à votre nom dans les réglages d’export, le texte copié affiche `Nom (Me)`. La personne qui reçoit voit une personne, pas un marqueur.

## Ce qui ne va pas dans la relance

- L’enregistrement, sauf s’il a été demandé et que vous pouvez l’envoyer.
- Une transcription tour de parole des apartés.
- Un profil vocal, un glossaire, ou tout réglage qui n’est pas un résultat.
- Des clés de preuve internes. Elles sont retirées du chat copié et des documents. La note lisible ne doit pas les contenir.
- Une seconde version, plus douce, d’une décision qui contredit la ligne. Modifiez la ligne, puis copiez.

Une relance qui reformule la décision plus mollement devient la version dont le client se souvient. La ligne et le message doivent dire la même chose.

## Quand l’autre côté veut une autre forme

Certains veulent une note d’état pour tout un projet, pas le récit d’une heure. Un document de projet peut s’appuyer sur les séances classées dedans. La mise à jour de statut de projet est faite pour ce document d’ensemble, pas pour un seul appel. Épinglez-la sur le projet si vous la réutilisez.

Certains ne veulent que les actions, en tableau : description, responsable, échéance. Copiez Actions quand c’est tout le message.

Certains seront dans la salle la prochaine fois et n’ont besoin que des questions ouvertes. Envoyez ces trois lignes. Une relance longue n’est pas plus complète. Elle est plus difficile à traiter.

L’export et le partage sont regroupés sous [exports](/fr#exports). Le procès-verbal que vous copiez est décrit sous [le compte rendu](/fr#record). Si vous voulez la fiche vide plutôt qu’un brouillon, le [modèle de procès-verbal](/fr/outils/modele-proces-verbal) reprend les mêmes titres sans audio. Le canevas plus large, avec exemples, est le [modèle de procès-verbal](/fr/blog/modele-proces-verbal-reunion).

## Questions fréquentes

### Une relance à partir des notes de réunion est-elle le procès-verbal ?

Le procès-verbal est le compte rendu. La relance est la partie que vous envoyez. Elles ne doivent pas se contredire. La relance est en général plus courte.

### Puis-je envoyer la relance sans l’enregistrement ?

Oui. Copiez le résumé, les décisions ou un document. L’audio reste sur le Mac, sauf si vous l’exportez vous-même.

### Et si j’ai besoin d’un PDF ?

L’app écrit du Markdown et peut remettre une note à Notes. Collez ce texte là où le PDF est produit. Il n’y a pas d’export PDF ou DOCX dans Vemoir.

### Un second export crée-t-il une seconde note Apple ?

Pas tant que Vemoir a l’identifiant. Un export ultérieur met à jour la même note. Si vous avez supprimé la note dans Notes, l’export suivant ne peut pas mettre à jour ce qui n’existe plus.

### Les notes saisies apparaissent-elles dans la relance ?

Elles peuvent, parce qu’elles nourrissent le résumé, les actions, les décisions et les documents. Elles gardent leur propre marque. Elles ne sont pas présentées comme une phrase prononcée.

### Le navigateur rédige-t-il le message ?

Le modèle de procès-verbal, non. C’est une fiche vide que vous remplissez et copiez. L’app Mac peut proposer les sections à partir de l’enregistrement, et vous copiez le résultat.

### Qui est « moi » dans la note copiée ?

Définissez votre nom d’export pour que `ME` s’affiche avec votre nom et `(Me)` à côté. Sinon, le destinataire voit le marqueur.

Copiez les décisions et les actions le jour de l’appel. Les commandes de ce passage sont sous [exports](/fr#exports).
