**WhatsApp voice to text** means taking a voice message you already have and turning that audio into words. It does not mean a browser extension that listens inside WhatsApp. The message has to exist as a file the transcription page can open, in a format it accepts, and short enough to run. On vemoir.ch that file path is the [voice memo transcription](/tools/transcribe-voice-memo) tool.

The limits are the same as the other browser tools: **15 minutes**, **3 successful runs a week**, MP3, M4A, WAV, or MP4. The file is not uploaded. Speakers are not labeled.

## Get the voice message out of the chat

WhatsApp stores voice messages inside the chat. The transcription tool never sees the chat. You export or save the audio first, on a device you are allowed to use.

<ul class="blog-facts">
  <li><span class="blog-kicker">Export</span><strong>M4A or OPUS</strong><p>Save to Files on the Mac first.</p></li>
  <li><span class="blog-kicker">Browser</span><strong>15 minutes</strong><p>MP3, M4A, WAV, or MP4 in the tab tool.</p></li>
  <li><span class="blog-kicker">Live call</span><strong>Not here</strong><p>Browser tools do not capture WhatsApp calls.</p></li>
</ul>


On a phone, open the chat, use the share or save option WhatsApp shows for that message, and move the audio somewhere you can reach from the computer. Chat export with media, in WhatsApp’s own menu, produces a folder of files plus a text log. Use the audio file, not the `.txt` log. The log is not the speech.

On WhatsApp for Mac, the same idea holds: save the message out as a file, then switch to the browser tool. Do not expect the website to read WhatsApp’s library in place. It will not.

A forwarded voice message is still someone else’s recording. Saving it for your notes does not expand what you may do with the words. If the sender expected the message to stay in the chat, ask before you transcribe it into a document you will forward again.

Group chats multiply that problem. One voice note can include a person who was not speaking to you. Transcribe only what you have a reason to keep, and do not drop the full text into another chat by default.

## WhatsApp voice to text in the browser

1. Save the voice message as a file you can open in Finder.
2. If it is already MP3, M4A, WAV, or MP4 and under 15 minutes, you can skip conversion.
3. Open [transcribe a voice memo](/tools/transcribe-voice-memo).
4. The model downloads once into the browser. Later runs can work offline. The Network panel in developer tools is the check that the audio file itself is not posted to a server.
5. Run the file. You get text. You do not get speaker labels. A voice message is usually one person, so the missing labels matter less than they do on a meeting. A message where two people passed the phone will read as one stream.
6. Copy the text into your notes. The page does not file it into WhatsApp.

Public Whisper models are what the page uses. Swiss German usually comes back as Standard German. If the voice note is dialect and you need the dialect spelling, this tool will disappoint you. Read the Standard German as a draft and correct the words that matter. There is no accuracy percentage to quote.

Three successful runs per week is a hard cap. A string of 20 voice messages on a Monday will not all fit. Prioritize the ones that carry a decision or a quote you must get right. The rest can wait until the next week or move to a local app that is not on the weekly counter.

The same limit and the same no-upload rule are described for interviews in [transcribe an interview without upload](/blog/transcribe-interview-without-upload). A WhatsApp note is shorter than most interviews and otherwise the same privacy shape: file in, text out, audio not sent to Vemoir.

For a live WhatsApp call on the Mac, the browser tool does not help. [How Vemoir records](/#capture) uses microphone and system audio with no bot in the participant list.

## When the browser tool is enough

One saved voice note, under 15 minutes, usually one speaker, and you only need text to paste into mail or notes: stay on the [voice memo page](/tools/transcribe-voice-memo). You do not need speaker labels, a minutes layout, or a project archive. If three runs a week cover your volume, buying an app would be premature.

Skip the browser when you batch many notes the same day, when a single message runs past 15 minutes after export, or when the audio is still inside WhatsApp and you refuse to save it out. Those cases need conversion plus either trimming or the Mac import path below.

## Where the Mac app fits better

Several voice notes per week, notes that belong in one client record, or follow-up drafts from the same thread: import converted M4A into the Mac app and keep transcript and summary on the machine. Live WhatsApp audio on the Mac (call audio through the speakers) is the same pipeline as Teams or Zoom: start recording before the call, stop after, transcribe locally. Requirements and models are on [capture and models](/#capture).

## When the file is the wrong format

WhatsApp often saves voice messages as Opus in an Ogg container. That extension is not on the tool’s list. MP3, M4A, WAV, and MP4 are. Convert before you open the page.

On a Mac, `afconvert` is the built-in converter. In Terminal, from the folder that contains the file:

```bash
afconvert -f m4af -d aac input.ogg output.m4a
```

Use the real file names. If `afconvert` refuses the Opus file, export again from WhatsApp or use the share sheet to a format the Music app or Voice Memos will accept, then export M4A from there. Do not run a random “converter” website. The point of this workflow is that the audio stays on the machine. Uploading it to a converter undoes that.

After conversion, check the duration. A voice message over 15 minutes needs to be trimmed or handled outside the browser tool. Splitting one long note into many pieces spends multiple weekly runs. Trim to the minute you actually need.

The Mac app can import MP3, M4A, WAV, AIFF, CAF, and FLAC through the same local pipeline as a meeting. Opus is still not on that import list. Convert first, then import if the note is part of a project rather than a one-off paste. 

## A live WhatsApp call is not a voice message

A voice message is a file. A WhatsApp call is live audio. The browser tool does not join WhatsApp, does not read the call, and does not capture the tab. If you need notes from a call that is happening now, the call has to play on the Mac and a local recorder has to be running.

That recorder is the Mac app: microphone and system audio, no bot in the call, transcription on the machine after you hang up. The macOS permission for other apps’ audio is Screen Recording, used for audio only. It does not capture the screen. You still tell the other person. WhatsApp will not show a “Vemoir is recording” banner.

If you only needed the voice message, do not buy a workflow for live calls. Save the file, convert if needed, and use the voice-memo page.

If the text is going into minutes with decisions and owners, paste it into the [minutes sheet](/tools/minutes-sheet) and edit. A raw transcript of a voice note is usually one paragraph. The minutes still need a date, a name, and what you will do next. [Meeting minutes template](/blog/meeting-minutes-template) is a structure you can copy when the note is really a decision, not a chat.

## Frequently asked questions

### Can the website read WhatsApp directly?

No. Save the audio file, then open the transcription tool. There is no WhatsApp login and no extension.

### Does WhatsApp Web pass audio straight into the tool?

No. WhatsApp Web still keeps voice notes inside the chat until you save or export them. Download or forward the message to Files, then open the file in the transcription page.

### What is the length limit?

15 minutes per file, and 3 successful runs per week, on the browser tools.

### Does the audio upload?

No. The model runs in the browser. Use the Network panel if you want to see that the file is not sent to Vemoir.

### Why did my .ogg file fail?

Opus/Ogg is not in the accepted list. Convert to M4A, MP3, WAV, or MP4 on your Mac, then try again.

### Will it keep Swiss German dialect?

Expect Standard German from the public Whisper model. Correct the draft. Do not promise dialect output.

### Are there speaker names?

No. Browser tools do not separate speakers. A single voice message rarely needs them.

### Can I transcribe a WhatsApp call live in the browser?

No. Live capture is not a browser feature. A voice message you already received is the case this page covers.

### Is this the same tool as a meeting transcription?

It is the same family of limits, on the voice-memo page. Meetings with several speakers and a minutes workflow are a different job from one saved bubble.
