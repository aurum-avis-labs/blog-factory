Redact a PDF in the browser when the file is already on your machine and you need a copy you can send. Drop it on the [PDF redactor](/tools/pdf-redactor), read the suggested spans, approve what should disappear, and download a flattened PDF. The file stays in this tab. A local model may download once so it can suggest personal data. The PDF itself is not posted.

This is a review aid. It is not proof that every private detail is gone. Scanned pages without a text layer need a box you draw yourself.

## How to redact a PDF without uploading it

<ol class="blog-steps">
  <li data-step="1"><h3>Drop the PDF</h3><p>The scan starts on its own. A sample file is there if you want to see the shape first.</p></li>
  <li data-step="2"><h3>Read the list</h3><p>Emails and phone numbers come from patterns. Other personal details come from a local model. Click a row to jump to that page.</p></li>
  <li data-step="3"><h3>Approve or keep</h3><p>Nothing is hidden until you approve it. Mark a rectangle when the model missed a logo, a photo, or a scan.</p></li>
  <li data-step="4"><h3>Download</h3><p>Save the flattened PDF. The page on screen stays so you can keep reviewing.</p></li>
</ol>

Zoom sits on the page. Page controls sit under it. The list of suggestions is where you decide what to hide.

If the PDF is a scan, or the text is only in an image, the model has nothing to read. Draw the areas yourself. For a meeting that still has to be recorded, the path is the Mac app, not this page. A transcript you already have can be cleaned or turned into notes without a second upload, which is the job of [transcribe an interview without uploading](/blog/transcribe-interview-without-upload).

## Before you send the file

Open the download and look at every page, not only the first. A box should cover the whole glyph, including letters that drop below the line. If a corner of a word is still visible, mark that area and export again.

The three free scans are shared with the other browser tools that run a model. The sample does not spend one. Closing the tab stops a scan that is still running.
