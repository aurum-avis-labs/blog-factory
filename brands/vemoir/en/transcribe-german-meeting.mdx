To **transcribe a German meeting** is to get Standard German on the page: readable Hochdeutsch, not a dialect script and not a certified verbatim. You either already hold a file (export, local Zoom audio, recorder) or you will capture the next Sitzung on this Mac. Public speech models write Standard German. Vemoir does not claim dialect output. If the room speaks strongly in dialect, expect Standard German spelling, gaps, or both, not a dialect transcript.

The practical path is local: import the file or record from the menu bar, and run the model on the Mac. For a short clip with no install, use the free [transcribe recording tool](/tools/transcribe-recording). The file is not uploaded to Vemoir. Limits: 15 minutes, 3 successful runs per week, no speaker labels, no live capture in the tab.

## What "transcribe a German meeting" means here

Standard German is the written form you expect in DE, AT, and in formal Swiss minutes: standard spelling, ordinary technical terms, names you will still fix. It is not:

The app UI can be German while the speech model transcribes German. Those settings are independent. Vemoir's interface exists in English, German, French, Italian, and Dutch. Proper names, product codes, and internal jargon are the usual cleanup. A project glossary on the Mac (preferred spellings and aliases) helps generated notes. The original transcript remains the evidence; the glossary does not rewrite the recording.

## You already have a file

1. Put the audio on the Mac. Vemoir imports MP3, M4A, WAV, AIFF, CAF, and FLAC. The browser tool accepts MP3, M4A, WAV, or MP4.
2. Play ten seconds. If the file is silent, you have a capture problem, not a German problem.
3. Under 15 minutes: choose the file in the [transcribe recording tool](/tools/transcribe-recording). The model downloads once; later runs can work with the network off. The Network tab should show that the audio was not posted to Vemoir.
4. Longer meetings: import into the Mac app (picker or drag and drop), optionally into a project. Transcription and speaker separation run on the device.

Local Zoom recordings are often `audio_only.m4a`, not a ready transcript. See [how to transcribe a local Zoom recording](/blog/zoom-local-recording-transcript). Interviews that must not go to a cloud vendor are covered in [transcribe an interview without uploading](/blog/transcribe-interview-without-upload).

## Record the next German meeting on the Mac

If the meeting is still ahead and this Mac will play the call:

1. Allow the microphone and **Screen Recording**, the macOS permission that covers other apps' audio. Vemoir uses it for meeting audio and never records the screen. No bot joins the participant list.
2. Start from the menu bar once Zoom, Teams, Meet, or another app is playing sound on the Mac. Any meeting app that plays audio works; see [platforms](/#platforms).
3. After you stop, the transcript is built from the finished local audio, not from the live preview.
4. Rename speakers, edit minutes and decisions on the Mac. Share only what you deliberately export.

Intel Macs are not supported. Apple silicon, macOS Sonoma 14.2 or later. Internet for setup and model download; afterward the workflow can run offline.

Want to test a short German clip without an upload? [Open the transcribe recording tool](/tools/transcribe-recording).

## Where the text breaks even when everyone spoke Standard German

Overlapping talk, weak speakers, hold music, acronyms the model has never seen: that is audio quality, not "German failed." Whispered remarks in a large room will come out patchy.

<ul class="blog-checklist">
  <li>Pick the language that matches most of the call before you transcribe.</li>
  <li>Rename speakers after import; profiles are optional.</li>
  <li>Export only the sections you may share.</li>
</ul>


Mixed-language turns (a German sentence, then English) are a different job. This article assumes the meeting is Standard German.

Cloud notetakers with a bot in the room are the better path when the company mandates one shared archive and the extra participant is allowed. Local is the better path when the file should not land on someone else's disk and nobody should see a bot. Pattern comparison: [meeting notes without a bot](/blog/meeting-notes-without-a-bot).

## What you still do after the transcript exists

Read the passages you will quote. Lock names and numbers. A generated protocol is not a board resolution just because it is in German. Consent and retention stay with you. This page does not say "GDPR-certified" or "nDSG-compliant."

Speaker labels exist in the Mac app, not in the browser. The browser does not separate speakers. Long files belong in the app, not in three 15-minute tabs, if you want one continuous record.

## A concrete German call, start to notes

Imagine a 40-minute vendor review in Standard German on Teams: you start Vemoir from the menu bar when sound plays, stop when the call ends, then rename speakers and edit the decision draft. Names like "Maier" vs "Meyer" still need a normal cleanup pass, not dialect work.

If the meeting lives only as a Teams cloud file, you may already have the platform transcript. A personal download does not replace the tenant copy.

If someone hands you a 12-minute M4A extract, the browser tool is enough for a first pass: copy the text and fix names. Stay within 15 minutes and the weekly cap. Speaker labels stay in the Mac app.

## Frequently asked questions

### Can I transcribe a German meeting without uploading the file?

Yes. In the browser the file stays in the tab (15 minutes, 3 runs per week). In the Mac app, transcription runs on the device. Neither path sends the recording to Vemoir. Export, or an API key for text models, is a later explicit step and does not transcribe the audio in the cloud.

### Does Vemoir write Swiss German dialect?

No. This article does not claim dialect output. The target is Standard German.

### Which model should I pick for German?

Pick an installed model that covers German. Parakeet v3 includes 25 European languages. Whisper Turbo, Medium, and Large-v3 each have their own coverage. There is no accuracy ranking here.

### Does the browser handle speaker changes in German?

No. Browser tools do not add speaker labels and they do not record live. Speaker separation is the Mac app.

### Is a Teams cloud transcript enough if the meeting was in German?

That transcript already ran on the vendor's side. Local means you hold the audio and run the model yourself. Both can write German. They are not the same processing location.

### Does the Mac app run on Windows?

No. Apple silicon only. For a short clip, the browser tool runs in a tab on whatever OS hosts the browser.
