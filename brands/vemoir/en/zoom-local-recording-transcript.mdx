To transcribe a Zoom recording after the call, start from the audio file on the computer that pressed record. Zoom writes a separate transcript only for a cloud recording, on a paid plan, with cloud recording and audio transcription turned on. A local recording, the path Zoom's help calls **Record on this Computer**, is video and audio on disk. There is no VTT in that folder.

This is the after-the-call job: find the folder, pick the audio file, and turn it into text without uploading the meeting. If you wanted Zoom to email you a transcript and you recorded locally, the missing email matches [Zoom's own rule](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0065911): audio transcription applies to cloud recordings, not to computer recordings stored on the device.

## Why the folder has audio, not a transcript

Zoom's help on [using audio transcription](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0064927) lists three requirements: a Pro, Business, Education, or Enterprise account, cloud recording enabled, and audio transcription enabled. After a cloud recording finishes, Zoom emails that the recording is ready, then emails again when the transcript is ready. That transcript is a VTT file in the cloud recording, not a file Zoom drops into Documents.

The article that explains how to [enable audio transcription](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0065911) says transcription only applies to cloud recordings. The same page says cloud audio transcription supports English. The "using" article says you can change the language of a cloud transcript and have Zoom reanalyze it. If those two pages disagree for your account, the control you see in the Zoom portal is the one that applies. Neither page gives a local recording a VTT.

A free account can still record to the computer. [Finding your recordings](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0058006) says computer recording is available to free and paid accounts. What you do not get on that path is Zoom's transcript.

## Where Zoom saves the local recording

In the meeting, the host records, or grants someone else the right to record. Zoom's [starting a computer recording](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0076922) says: click **Record** in the meeting controls, then **Record on this Computer** if a menu appears. People who dial in hear that the meeting is being recorded, unless the host has turned that announcement off.

When the meeting ends, Zoom converts the recording. Leave the laptop awake until that conversion finishes. Zoom's help says an interrupted conversion (sleep, shutdown, or closing the lid) can leave files corrupted and not recoverable. When conversion succeeds, the folder opens on its own.

Default locations, from the same "finding recordings" article, as of September 2026:

- Mac: `/Users/[Username]/Documents/Zoom`
- Windows: `C:\Users\[Username]\Documents\Zoom`
- Linux: `home/[Username]/Documents/Zoom`

Each meeting gets its own subfolder. If someone changed the path, the Zoom desktop app still knows it: profile picture, **Settings**, **Recording**, then **Open** or **Change** next to the local storage location. Zoom recommends keeping that location on a local drive. A cloud-sync folder (Dropbox, Google Drive, OneDrive), an external disk, or a network drive can break the save and the conversion.

If the folder looks empty, check you did not record to the cloud. The Zoom web portal has a second way to see the path: **Recordings & Transcripts**, then the **Computer recordings** tab. The **Location** column lists where that computer put the files. Cloud recordings live on the other tab, and that is where a VTT would be.

## Which file to open

Zoom's [file format article](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0064394) names the current defaults:

- `video[number].mp4` for picture and sound
- `audio[number].m4a` for audio only
- `chat.txt` if in-meeting chat was saved
- `audio[Name][number].m4a` if you recorded a separate audio file per participant

Use the M4A. It is the speech, without the video. Transcribe one mixed audio file, not a pile of per-person tracks, unless you already know you want them separate.

Older folders, and a lot of campus guides, still show `audio_only.m4a` and `zoom_0.mp4`. Zoom's current format article does not use those names. If your folder has `audio_only.m4a`, that is the file. If it has `audio` plus a number and `.m4a`, that is the file. Keep the whole folder until you trust the text. A local recording exists on that computer. Zoom does not keep a backup copy of it.

## Cloud VTT and local M4A

| What you recorded | Typical files | Transcript from Zoom? |
| --- | --- | --- |
| Cloud, on an eligible paid plan, with audio transcription on | MP4, M4A, and a VTT | Yes, after Zoom processes it |
| Computer (**Record on this Computer**) | `audio[number].m4a` or, in older folders, `audio_only.m4a`, plus MP4, sometimes `chat.txt` | No |

A VTT is timed text. If you already downloaded one from a cloud recording, the [transcript cleaner](/tools/transcript-cleaner) strips cue numbers and timestamps in the browser. It does not transcribe audio, and it does not spend one of the three weekly transcription runs. A local M4A still needs speech-to-text. You do not need the MP4 for a transcript.

## How to check nothing was uploaded

1. Open the tool and start a run with your Zoom M4A.
2. Open Developer Tools. In Chrome, View, Developer, Developer Tools. Or right-click the page and choose Inspect.
3. Open the Network tab. Filter by Fetch/XHR if you see that filter.
4. Watch the requests while the job runs.

You should see the model or its assets download on first use. You should not see your meeting audio posted as a file upload. If a security review asks for proof, this is the check. It is your browser's log, not a certificate from us.

## Frequently asked questions

### Does Zoom transcribe local recordings automatically?

No. Audio transcription produces a VTT for cloud recordings when the feature is on, on an eligible paid account. **Record on this Computer** leaves audio and video on disk ([Zoom help](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0065911)).

### Where is my Zoom recording on a Mac?

Look in `/Users/[your name]/Documents/Zoom`, then the folder for that meeting ([Zoom help](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0058006)). If you changed the location, use Settings, Recording, Open.

### Where does Zoom save local recordings on Windows?

The default is `C:\Users\[your name]\Documents\Zoom`. Each meeting has its own subfolder. The Computer recordings tab in the Zoom portal shows the Location column if the folder was moved.

### Which file should I transcribe, MP4 or M4A?

The M4A. Zoom's format article calls it `audio[number].m4a`. Many folders still use `audio_only.m4a`. Use the MP4 only if there is no audio-only file.

### Do I need a paid Zoom plan to transcribe a local recording myself?

No. Computer recording is on free and paid accounts. A paid plan with cloud recording is what adds Zoom's own transcript, and only for the cloud copy.

### Is the free tool private?

The Zoom file is processed in the browser and is not uploaded to Vemoir. The first run downloads the model. Use the Network tab if you need to see that. Speaker labels and live recording are not part of the browser tools.

### What if the file is longer than 15 minutes?

The free browser tool stops at 15 minutes and at three successful runs a week. Import the full local file in the Mac app, or split the M4A if you must stay in the browser. Any copy you make is still your recording to store and to explain to the people in the meeting.

### Will Swiss German stay Swiss German?

Usually not, in the browser. Public Whisper models tend to write Standard German from Swiss German speech. Plan for that if you will quote the text.

### The folder never opened. Is the recording gone?

Often it is still converting, or the save location is not Documents/Zoom. Check Settings, Recording. If the laptop slept during conversion, Zoom warns the file can be corrupted. The Computer recordings tab shows whether Zoom thinks a local file exists, and where.
