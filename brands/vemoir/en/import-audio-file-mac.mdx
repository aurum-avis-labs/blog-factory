To **import an audio file on a Mac** and get a transcript, the recording already exists. The job is speech-to-text on that file without turning import into an upload. In Vemoir you drop the file into the Mac app (picker or drag and drop), assign a project if you want, and run the same local pipeline as a menu-bar recording. In the browser you can do the same for a short clip without sending the file to Vemoir.

This is the after-the-call path. It does not record a live meeting and it does not add a bot to Zoom or Teams. To capture the next call on this Mac, use [menu-bar recording](/#capture), not import.

## What you can import on a Mac

Vemoir imports common local audio: **MP3, M4A, WAV, AIFF, CAF, and FLAC**. Export from a recorder, a meeting app's local folder, or an interview kit before you drag them in.

<ul class="blog-facts">
  <li><span class="blog-kicker">Mac app</span><strong>MP3, M4A, WAV</strong><p>Also AIFF, CAF, and FLAC on import.</p></li>
  <li><span class="blog-kicker">Browser tool</span><strong>15 min cap</strong><p>MP3, M4A, WAV, or MP4. Three runs per week.</p></li>
  <li><span class="blog-kicker">Not audio</span><strong>VTT or TXT</strong><p>Already text. Clean or summarize, do not re-import.</p></li>
</ul>

Files people try that are not on this list:

- **MP4 video.** The Mac app import list is audio. If Zoom left a movie, look in the same dated folder for `audio_only.m4a`. The browser tool accepts MP4 (and MP3, M4A, WAV) for a short file.
- **VTT or TXT.** Already text. Import will not improve a caption file.
- **A cloud recording link.** Import needs bytes on disk. Download the audio first. Downloading a cloud transcript is not local transcription; the vendor already ran speech-to-text.

iPhone voice memos usually land as M4A after AirDrop or Files. That is a normal import once the file is local.

Mac app requirements: Apple silicon (M1 or newer), macOS Sonoma 14.2 or later, room for the models. Intel Macs are not supported. Internet is for setup and model downloads. After that, processing can run offline. See [offline transcription on a Mac](/blog/offline-transcription-mac) when you need the full workflow without the network.

## Three files people import after a call

**Local Zoom folder.** After "Record on this Computer", `audio_only.m4a` often sits next to the video. Import the M4A, not the MP4 movie. Longer than 15 minutes stays in the Mac app; an eight-minute file can stay in the browser if you only need raw text once.

**AirDropped voice memo.** The phone sends M4A. Content is whatever the phone microphone heard: a room conversation yes, a Zoom call on another laptop no. [Transcribe a voice memo on a Mac](/blog/transcribe-voice-memo-mac) covers the same path with more Finder detail.

**Dictaphone export.** WAV and FLAC work in the Mac app. Play ten seconds before import. Some devices write a silent first file if you started recording before anyone spoke.

After transcription, one pass over names, amounts, and the next step's date is usually enough. The project glossary keeps recurring spellings consistent. It does not replace proofreading, especially before you quote a sentence.

## Import vs recording the call yourself

Import is for audio that already exists: a colleague's Zoom local file, a handheld recorder, a dictation you will not repeat.

Live capture is for the next meeting on **this** Mac: microphone plus system audio, no bot in the list. Import cannot add system audio that was never in the file. If the M4A is mic-only, you will not recover the remote side by importing into a different app.

Do not import a silent file and expect a transcript. If playback is empty, fix capture next time. [Meeting recording with no sound on a Mac](/blog/meeting-recording-no-sound-mac) is a recording problem, not import.

## The browser path: short files, no install

The free [transcribe recording tool](/tools/transcribe-recording) runs in your tab. Choose MP3, M4A, WAV, or MP4. **The file is not uploaded to Vemoir.** A public Whisper model downloads once; later runs can work with the network off. Check the Network tab if you need to show someone the audio did not post to a server.

Limits as of September 2026:

- **15 minutes** per file
- **3 successful runs per week**
- **No speaker labels**
- **No live meeting recording** in the browser

Split a long file if you stay in the tab, or use the Mac app for the whole recording. For interviews and consent paperwork, see [transcribe an interview without uploading](/blog/transcribe-interview-without-upload).

## After import: what you can share

The useful export is usually minutes, decisions, and actions, not the audio. Keep or drop the recording per your retention choice. Vemoir can remove the per-meeting audio folder after a successful pass if storage is set that way. The written record can still point at transcript lines on the Mac.

Do not call the output a certified transcript. Do not call it GDPR-certified or privileged. Consent and deletion remain yours. If the imported file was someone else's recording, import does not fix missing consent.

## When another path is better

- **The official file must live in Teams or Zoom.** A private download does not replace the tenant's recording.
- **You need a company archive today.** A file on one Mac is not a shared workspace. Export the notes.
- **The file is 12 minutes long and you need raw text once.** There is less setup in the browser.
- **No Apple silicon.** The Mac app will not run. Use another tool on your system, or the browser for a short clip.

## Frequently asked questions

### Can I import an audio file on a Mac that I recorded on my phone?

Yes, once the file is on the Mac (AirDrop, Files, USB) and in a supported audio format. The phone recording is only what the phone microphone heard. It will not include a Zoom call that played on a different device.

### Does import upload the meeting to Vemoir?

No. The Mac app processes locally. The browser tool does not send the file to Vemoir either. Exporting, or opting into a cloud **text** model with your own key, is a later, explicit choice.

### Which formats does Vemoir import?

MP3, M4A, WAV, AIFF, CAF, and FLAC in the Mac app. The browser tool accepts MP3, M4A, WAV, or MP4, with the 15-minute cap.

### Can I import while a live meeting is still going?

You can import an old file at any time. Import does not capture the live call. For the live call, start recording from the menu bar with microphone and system audio allowed.

### Do imported files get speaker labels?

On the Mac app, speaker separation runs locally. You rename labels; profiles are opt-in. The browser tool does not separate speakers.

### What if the imported transcript is in the wrong language?

The app interface language (English, German, French, Italian, Dutch) is independent of the speech model. Pick a model that covers the spoken language. Parakeet v3 covers 25 European languages. The Whisper variants have their own coverage. There is no accuracy ranking on this page.
