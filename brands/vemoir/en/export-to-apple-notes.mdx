**Export to Apple Notes** sends a meeting record into a Notes account and folder you choose. Vemoir stores the note identifier. The next export updates that note instead of leaving a second copy beside it. You always see a combined-note preview before the handoff.

The audio never travels with the note. You export the record: the text sections you selected.

## What lands in the Apple Notes note

The note carries the canonical summary, key points, risks, open questions, decisions, actions, participants, custom documents, and Vemoir provenance. Derivative blocks that only repeat the summary are omitted. Notes you typed during the meeting stay your text. They are not pasted in as transcript quotes.

Optional automatic export runs after a meeting processes successfully. Leave it off when you want the preview every time. Automatic still sends text only. It does not share audio.

Want the folder chosen before the call starts? File the meeting under a [project](/blog/meeting-projects) and set the Notes path there.

## What stays on the Mac

Transcription, speaker separation, and the recording remain on the Mac. Apple Notes receives exported text through the destination you picked. A bring-your-own API key, if you use one for generated text, is separate: text-only, Keychain-stored, explicitly enabled. It does not replace Notes and does not send audio. A failed Notes export does not fall through to another cloud notebook.

Deleting the meeting or purging audio in Vemoir does not remove a note you already sent. Deleting in Notes is its own step. Updating from Vemoir overwrites Vemoir-managed content in that note, so read the preview when the minutes changed materially.

Identity settings can map `ME` to your real name and show `Name (Me)` in copied or shared content. Set that before a client-facing export if bare `ME` would look unfinished.

Speaker names in the note match the record at export time. Rename anonymous clusters without creating a voice profile, then export again. An encrypted profile from "Remember this speaker" is not part of the note body.

## iCloud, permissions, and the wrong account

Notes sync through iCloud on the account you selected. Vemoir writes the note on this Mac; Apple handles sync to your other devices under Apple's rules. If the note is missing on a phone, check that the same iCloud account is enabled in Notes there.

macOS may ask whether Vemoir may write to Notes. That prompt is about the note, not screen recording. System audio for meetings uses Screen Recording permission when you capture.

If a note lands in the wrong Apple Notes account, turn off automatic export, pick the account again, and export manually once. The stored identifier belongs to the note the last successful run created or updated. Switching accounts without a new export does not move the old note.

## Where Apple Notes is the wrong destination

Export to Apple Notes fits when you already work in Notes, want one note per meeting that stays current, and choose the folder yourself. Skip it when:

- The client requires a PDF in a data room or a shared drive with fixed naming. Copy the text into the format they asked for. This path does not emit PDF or Word.
- Several people must co-edit one living document with comments. Notes sharing follows Apple's rules after export. Vemoir does not add a team workspace.
- You need the recording inside the note. Export is the record, not the audio files.
- Speaker names or [project glossary](/blog/project-glossary) spellings are still wrong. Fix them, regenerate if needed, then export.

Copy to the clipboard remains for a summary, a document, or minutes when you do not want Notes. Toolbar sharing follows the view you are in: summary, actions, decisions, or transcript.

## Project exports versus meeting actions

You can export from a single meeting's actions or from Project Exports for meetings tied to that mandate. Both paths use the stored note ID per meeting, not one shared note for the whole client. If you want a fresh note per weekly call, export each meeting separately. If you want one living note per meeting, export the same meeting again after you edit the record.

Custom documents you generated in Vemoir can appear in the preview when you include them in the export. They do not replace the transcript. They are formatted text for clients or internal distribution. If a document still shows `ME`, fix identity before export.

## After you regenerate, export again

You correct a speaker label and a glossary entry, then regenerate the minutes. Yesterday's Apple note still shows the old names until you export again. The update reuses the stored note ID, so Notes should not grow a second page with nearly the same title. Cancel from the preview if something still looks wrong; the previous note stays until a new handoff succeeds.

With automatic export on, a successful processing pass attempts that update without an extra click. Turn it off for sensitive clients when you want eyes on every preview. Errors do not route to email, another Notes account, or a cloud transcription vendor.

## Frequently asked questions

### Does a second export create a second Apple Notes note?

No. Vemoir stores the exported note identifier and updates that note. The preview shows the combined note before you hand it off.

### Can I choose the folder?

Yes. A project selects a real Apple Notes account and a nested folder.

### Can export run by itself?

You can export manually from meeting actions or Project Exports. A project can also export automatically after processing succeeds. You turn that option on.

### Does the note include the audio?

No. It includes the written record: summary, key points, risks, open questions, decisions, actions, participants, custom documents, and provenance.

### What if the update fails?

Retry state and errors are stored so you can see the failure. Check the Notes account and try again when the meeting is in a good state.

### Will unknown speakers be named in the note?

Only if you named them. Unknown speakers stay anonymous until you set a label or opt in to remembering a voice.

### Is this the same as the free browser tools?

No. Those tools transcribe a file in the browser, up to 15 minutes, with no Apple Notes handoff and no speaker labels. The Notes export is in the Mac app.

### Do I need a bot in the meeting for this?

No. You record on the Mac, then export the text you want. Nobody was added to the call.

### Do I need an iCloud account to see the note on my iPhone?

Only if you want the same note on several Apple devices. Vemoir writes on the Mac. Sync between iPhone and Mac runs through iCloud, according to your Notes account settings.

Pick the folder once, export when the minutes are right, and let the next export refresh that note. Controls are under [exports](/#exports).
