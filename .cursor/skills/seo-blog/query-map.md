# Query map

Assign every article exactly one type. The type sets the funnel and the outline. Mix a batch. A cluster of only comparisons, or only definitions, leaves the rest of the journey empty.

Default mix for a batch that is trying to grow a product: about 35% `awareness`, 40% `interest`, 25% `consideration`. A brand strategy file wins if it sets a different mix.

Each row is one query. Research it, then write the page that answers it. Each locale answers the query people type in that language.

| Type | `funnelStage` | The page must do this |
|---|---|---|
| What it is / glossary | `awareness` | Define the thing, who it is for, and the one mistake people make. |
| Problem or cost | `awareness` | Name the situation, why the usual fix fails, what "better" looks like. |
| How to do the job | `interest` | Steps, a tradeoff, and when to stop. One worked example. |
| Checklist, template, audit | `interest` | Something the reader can apply the same day. |
| Category vs category | `interest` | Two approaches, who each fits, a table only if the rows differ. |
| Best {category} for {audience} | `interest` | Inclusion rules first. A few options. Who should pass on each. |
| {Tool} alternative | `consideration` | What the incumbent is good at, where it stops, who should stay on it. |
| {A} vs {B} vs {C} | `consideration` | Same jobs compared. No single winner unless the audience is that narrow. |
| Is {product} worth it / when not | `consideration` | Limits, setup, and the reader who should not buy. |
| Workflow with named features | `consideration` | How the job actually runs in this product. Claims only from the product. |

Pillar pages are rare. Use one when the brand has no page that already owns the category. Spokes link to it. It links to spokes. One pillar per category.

## Outline

1. Opening: the query, the answer, who this is for.
2. One H2 per adjacent question (People Also Ask style): limits, cost, who it fails for, how it differs from the next option.
3. Under each of those H2s, a short direct answer before any detail.
4. A practical close: what to do next, plus one internal link.

## Cluster shape

For one product job, plan spokes across the types above instead of twenty "best tools" variants.

Example for a scheduling product:

- awareness: why the calendar and the published feed diverge
- interest: how to audit click-heavy posting; category of automation vs a scheduler
- consideration: Buffer alternative; Later vs Buffer vs a third tool; when this product is the wrong buy

Each row gets its own primary query. "Best scheduler", "top scheduler", and "best scheduling software" are one article, not three.

## Internal links

Plan the graph in the batch file before writing.

- Awareness may link to interest or consideration.
- Interest links sideways or down, toward a decision.
- Consideration links to other decision pages.
- Body hrefs follow the brand's existing pattern. Aurum German uses `/de/blog/{slug}`. Several product blogs use `/blog/{slug}` on the default locale.
