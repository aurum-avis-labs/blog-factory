# who-owns-the-code

## Verified

- Software created by an employee in the course of employment belongs to the employer (Art. 17 URG), via Rentsch summary: https://www.rentschpartner.ch/ict-law/schutz-von-software
- External author copyright on software generally remains with the author until a written assignment (Urheberrechtsabtretung), same source
- Ideas as such cannot be protected (IGE): https://www.ige.ch/de/uebersicht-geistiges-eigentum/ein-leitfaden-fuer-innovative-und-kreative/idee/koennen-ideen-geschuetzt-werden
- Aurum Product Validation Package: customer owns code, designs, data, and documentation (writer brief, service page facts)

## Not verified

- Whether every Swiss agency uses the same standard wording in MSAs; article stays on statutory defaults and contract checklist

## Do not claim

- That signing any contract automatically transfers all IP worldwide without reading third-party licences
- That repository access alone equals a clean chain of title if freelancers were not covered by assignment
- Package ownership line must still explain written assignment for external authors (calendar `apart`)
