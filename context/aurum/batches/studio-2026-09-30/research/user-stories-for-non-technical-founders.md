# user-stories-for-non-technical-founders

## Verified

- INVEST criteria for user stories (Independent, Negotiable, Valuable, Estimable, Small, Testable) are widely attributed to Bill Wake; summary on Martin Fowler's site: https://martinfowler.com/bliki/INVEST.html
- Scrum Guide describes product backlog items without mandating a single user-story sentence format: https://scrumguides.org/

## Not verified

- No single official standard for the exact «As a … I want … so that …» template as a requirement in Swiss procurement or agency contracts.
