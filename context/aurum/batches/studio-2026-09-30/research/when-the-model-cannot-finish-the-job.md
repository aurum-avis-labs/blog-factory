# when-the-model-cannot-finish-the-job

## Verified

- Postology built in 2024 before Aurum Avis Labs legal entity formation: case study HTML (`postology-case-study/index.html`)
- Problem: image models (deprecated DALL-E path in HTML) weak at dependable typography; overlay copy could not be trusted inside the generated image
- Design: multi-agent pipeline (topic framing, image prompts, caption and overlay text from topic-image pair, music by mood, format assembly); HTML overlay layer in application code for typography and layout
- Instagram API path for user connection and direct posting required a legal entity; publishing stayed manual (copy output) until API access viable
- Waitlist launch collected roughly 10 signups without active advertising or sustained promotion (HTML signal grid)
- Product not pushed as public scaled SaaS; continued internal evolution (newer models, campaigns, reference images, HTML overlays)
- Portfolio: `/portfolio/postology`, `/de/portfolio/postology`
- Brief: internal tool, not a public launch; do not sell to creators and brands per shorter portfolio blurb

## Not verified

- Current feature set of Postology beyond what the case study HTML describes
- Whether Instagram API access is live today for Aurum

## Do not claim

- Postology as a public product launch or creator/brand SaaS positioning
- Download counts, review anecdotes, or revenue
- That manual publishing is always acceptable for every social product
- Fake company names, quotes, ratings, or invented results (use real case only)
