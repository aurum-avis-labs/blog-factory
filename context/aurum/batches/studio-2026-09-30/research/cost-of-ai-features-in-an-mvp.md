# cost-of-ai-features-in-an-mvp

## Verified

- OpenAI publishes API pricing on a dedicated page; rates and model names change: https://openai.com/api/pricing/
- Anthropic publishes API pricing similarly: https://www.anthropic.com/pricing
- Azure OpenAI Service pricing is listed per region and model on Microsoft’s pricing page: https://azure.microsoft.com/en-us/pricing/details/cognitive-services/openai-service/
- Supabase offers a Zurich region (eu-central-2) for projects: https://supabase.com/docs/guides/platform/regions
- Apple App Store Review Guideline 4.2 expects more than a repackaged website: https://developer.apple.com/app-store/review/guidelines/

## Not verified

- Exact token counts for a typical MVP feature (depends on prompts, context length, and user behaviour).
- Whether a given Swiss founder’s chosen vendor bills in CHF or USD at checkout this quarter.

## Do not claim

- Specific per-token or per-month model prices (calendar `apart`: prices move; read the vendor page the week you build).
- That LLM spend in a ten-user pilot predicts cost at 10'000 users without load testing and caching design.
- That the cheapest model is always sufficient for regulated or high-stakes outputs.
