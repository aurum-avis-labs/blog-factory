# swiss-hosting-for-an-mvp

## Verified

- Supabase projects can be created in **Central Europe (Zurich), eu-central-2**, listed as a specific AWS region in Supabase region documentation: https://supabase.com/docs/guides/platform/regions
- Supabase states that region choice determines where primary project data is stored, that general region groupings may include multiple jurisdictions, and that region selection is a data-location control, not proof of regulatory compliance: https://supabase.com/docs/guides/platform/regions
- Aurum’s sold Product Validation Package deploys on Azure with React and NestJS (internal service page and writer brief; no Azure geography name cited in this article).

## Not verified

- Whether a given Lovable, Bolt, v0, or Replit export lets you change Supabase region after the first project is created (treat region as a setup decision; confirm in Supabase dashboard for the project).
- Default hosting region for each vibe-coding tool’s managed preview URL without opening that vendor’s docs for the current year.

## Do not claim

- Azure or AWS Swiss region names (for example Switzerland North or eu-central-2 for non-Supabase services) without a cited vendor page per calendar `apart`.
- That hosting in Switzerland alone satisfies FADP, GDPR, customer contracts, or sector rules.
- Specific latency, uptime, or franc hosting costs for Swiss versus EU regions.
