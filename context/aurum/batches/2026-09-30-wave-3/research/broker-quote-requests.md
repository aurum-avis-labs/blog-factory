# broker-quote-requests
Primary query DE / EN: Offertanfragen an Versicherer bündeln / send and compare quote requests to insurers
SERP (top results seen, what they cover, the gap we fill): Pages either sell a comparison platform or explain insurance cover. They rarely give a small Swiss broker a sequence: one fact sheet, the same request to several insurers, answers forced into the same rows, the recommendation written by the broker afterwards. This post is that sequence. It does not name insurer products or portal features.
Verified facts (one per line, each with URL and access date):
- FINMA: information to the client in an understandable form before the contract (Art. 45 VAG); untied intermediaries disclose remuneration from insurers or third parties (Art. 45b VAG). https://www.finma.ch/de/ueberwachung/versicherungsvermittler/pflichten-fuer-versicherungsvermittlerinnen-und--vermittler/ accessed 2026-09-30. Used only to say the comparison table is not that client information. The duties overview is the linked broker article.
