Verified facts (one per line, each with URL and access date):
- Microsoft 365 Copilot and agents retrieve data from Microsoft Graph and respect existing permissions, sharing settings, and policies. By default, SharePoint sets sharing to the most permissive option. Restricted Access Control can limit a site to a group even if older links exist. Restricted Content Discovery can keep a site out of Copilot and organisation-wide search while leaving permissions unchanged; it is for content that must stay accessible but not broadly discoverable. https://learn.microsoft.com/en-us/sharepoint/get-ready-copilot-sharepoint-advanced-management accessed 2026-09-30.
- Restricted SharePoint Search is retiring. From 31 July 2026, new enablement is blocked. It is a short-term measure, not a security boundary, and it does not change permissions. It does not guarantee that only allow-listed sites appear: recently accessed sites, and sites shared in Teams or Outlook, can still show up. It allows up to 100 sites. https://learn.microsoft.com/en-us/sharepoint/restricted-sharepoint-search accessed 2026-09-30.
- Gemini in Workspace has the same access to Workspace data as the signed-in user (Drive files shared with them, calendars they can view). If the owner blocks download, copy and print, Gemini cannot use that Drive file even when it is shared. An admin can turn off Gemini's access to Workspace data entirely. Delegated Gmail is not visible to Gemini. https://support.google.com/a/users/answer/17010577?hl=en accessed 2026-09-30.
- To use a Drive file as a Gemini source you need permission to view it. PDFs must be uploaded to Drive first. https://support.google.com/drive/answer/16813283?hl=en accessed 2026-09-30 (search extract of the official help page).
