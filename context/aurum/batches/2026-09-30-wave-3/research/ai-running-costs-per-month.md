# ai-running-costs-per-month
Primary query DE / EN: Was KI im Betrieb pro Monat kostet / what AI costs per month in operation
SERP (top results seen, what they cover, the gap we fill): Vendor pricing pages list dollars per million tokens. Comparison blogs restack those tables. They rarely separate a Swiss SME's hosting line from the usage bill, or show how document length and model choice move a monthly total. The operations post covers who runs the automation. This post is the usage bill.
Verified facts (one per line, each with URL and access date):
- Claude Sonnet 5 base input USD 2 per million tokens, output USD 10 per million. Cache hits USD 0.20 per million. Haiku 4.5 base input USD 1, output USD 5 per million. The USD 2 / USD 10 Sonnet 5 price, launched as introductory through 31 August 2026, is now the standard price; the rise to USD 3 / USD 15 on 1 September 2026 will not occur. Claude 4.7 and later, including Sonnet 5, use a tokenizer that produces approximately 30% more tokens for the same text; the exact increase depends on the content. https://docs.anthropic.com/en/docs/about-claude/pricing accessed 2026-09-30.
- Anthropic monthly spend caps on the fetched rate-limits page: Start USD 500, Build USD 1,000, Scale USD 200,000 per calendar month. Custom tier has no cap. You can view the cap and set your own limit on the Billing page. At the cap, API usage pauses until 00:00 UTC on the first day of the next month unless a higher limit is granted; requests return HTTP 429. Workspace limits can also be set. https://docs.anthropic.com/en/api/rate-limits accessed 2026-09-30.
- Gemini 3.8 Flash (`gemini-3.8-flash`) paid standard: input USD 0.75 per million tokens through 31 December 2026, USD 1.50 from 1 January 2027. Output, including thinking tokens, USD 3.75 through 31 December 2026, USD 7.50 from 1 January 2027. https://ai.google.dev/gemini-api/docs/pricing accessed 2026-09-30.
- OpenAI: spend alerts notify and do not stop traffic. A hard spend limit makes affected requests fail (HTTP 429). Enforcement is not instantaneous, so recorded spend can slightly exceed the amount. Organisation and project hard limits are separate. OpenAI also assigns a usage-tier limit. https://developers.openai.com/api/docs/guides/spend-limits accessed 2026-09-30.
- OpenAI's production guide: pay-as-you-go prices per 1,000 tokens, roughly equal to 750 words. The API returns token counts. Shorter prompts and caching reduce tokens; a smaller model reduces the price per token. https://developers.openai.com/api/docs/guides/production-best-practices accessed 2026-09-30.
Vendor / product features used (URL each): see the pricing and spend-limit URLs above. Aurum hosting CHF 50–150 per month, cancellable, AI usage on top, from WRITER-BRIEF section 8 only.
Not verifiable, therefore left out: a USD/CHF conversion; ChatGPT or Copilot seat prices; GPT-4o mini's dollar rate (the official model page mixed a "Batch API price" label with the figures, so the standard rate was not clean enough to quote); Google Search grounding overage (the line was incomplete in the fetch); any claim that one token count fits every provider.
