# auto-file-documents
Primary query DE / EN: Dokumente automatisch benennen und ablegen / name and file documents automatically
SERP (top results seen, what they cover, the gap we fill): Results mix DMS vendors and generic "document management" listicles. Official product help that is usable: Google's shared-drive guidance on organisation-wide naming and limited-access folders, and Microsoft's column settings that can require a value. The gap is the office decision before any product: one name pattern, one folder rule, a person confirms the unclear files, and retention is not the same as a tidy folder. Scanning paper is the earlier inbound step. Notice dates live in the contract register.
Verified facts (one per line, each with URL and access date):
- Google Workspace help: agree organisation-wide naming conventions for shared drives so people can find them and avoid name clashes. Examples Google gives include a region prefix and a status prefix such as archive or in progress, and a marker for external versus internal. Limited-access folders: only managers of the shared drive and people added directly to the folder can open it; other members see the name and cannot open it. https://support.google.com/a/users/answer/13015138 accessed 2026-09-30.
- Microsoft: a managed metadata column can be set so that "this column contains information" is required, and users must then enter a value. https://support.microsoft.com/en-us/sharepoint/data-and-lists/create-a-managed-metadata-column accessed 2026-09-30.
- SharePoint lists and libraries support added columns, including date columns. https://support.microsoft.com/en-us/sharepoint/lists/create-a-calendar-view-from-a-list accessed 2026-09-30.
- OR Art. 958f ten-year retention for books and vouchers, electronic storage if readable and faithful, signed annual and audit reports on paper: already used in digitise-paper-mail. https://www.fedlex.admin.ch/eli/cc/27/317_321_377/de accessed 2026-09-30. This post points there rather than repeating the ordinance.
Vendor / product features used (URL each): Google shared drives and Microsoft column requirement, URLs above. No claim that either product renames files with AI.
Not verifiable, therefore left out: auto-classification accuracy, a Microsoft or Google feature that "files any PDF by itself". Aurum has not built a DMS.
