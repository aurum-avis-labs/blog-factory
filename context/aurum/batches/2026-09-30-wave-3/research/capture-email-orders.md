Verified facts (one per line, each with URL and access date):
- Microsoft Graph v1.0 can list the attachment objects on a mailbox message. Least privileged permission named on the page: Mail.Read. Successful call returns 200 and a collection of attachment objects. https://learn.microsoft.com/en-us/graph/api/message-list-attachments?view=graph-rest-1.0 accessed 2026-09-30.
- Gmail API users.messages.attachments.get returns a specified message attachment. Scopes listed include gmail.readonly. https://developers.google.com/gmail/api/reference/rest/v1/users.messages.attachments/get accessed 2026-09-30.
- GS1 Switzerland: EDI is used to transmit transactional processes such as orders, order confirmations, delivery notes or invoices, in a standardised format. EANCOM defines the format for electronic orders and for master data such as price lists. In Switzerland a further reduced subset of EANCOM is offered as IDEAL messages. https://www.gs1.ch/en/barcodes-standards/gs1-standards/share accessed 2026-09-30.
- GS1 Switzerland, Ideal Message CH ORDERS, version 4.8.0, published December 2022, publisher GS1 Switzerland, based on EANCOM 2002: the message is intended for day-to-day ordering. Recommended business practice: one purchase order for one delivery in one location at one time. https://www.gs1.ch/en/media/1266 accessed 2026-09-30.
