# replace-access-database
Primary query DE / EN: Access-Datenbank ablösen / replace an old Microsoft Access database
SERP (top results seen, what they cover, the gap we fill): Microsoft documents edition end-of-support dates and a Dataverse migration that can leave Access as the front end. Partner pages push a full rewrite. The gap is a decision for a small Swiss office: keep, Lists, Dataverse, a standard program, or a small app, plus what the migration does not carry. Excel as a shadow system is a different file.
Verified facts (one per line, each with URL and access date):
- Microsoft's 2026 end-of-support list: after retirement or end of support there are no new security updates, non-security updates, free or paid assisted support, or online technical content updates. Access 2021 is listed under product retirements on 13 October 2026. Access LTSC 2021 is listed under fixed-policy end of support on 13 October 2026. https://learn.microsoft.com/en-us/lifecycle/end-of-support/end-of-support-2026 accessed 2026-09-30.
- Access 2024 lifecycle page: retirement date shown as 2029-10-09 (Pacific Time on the page). https://learn.microsoft.com/en-us/lifecycle/products/access-2024 accessed 2026-09-30.
- The Access 2021 lifecycle page shows a retirement timestamp of 14 October 2026, 6:59:59 AM Pacific. The 2026 summary list says 13 October 2026. Both are Microsoft pages; the article cites the summary list for the "no further updates" rule and the product page for the timestamp, and tells the reader to look up the exact edition. https://learn.microsoft.com/en-us/lifecycle/products/access-2021 accessed 2026-09-30.
- Access Services web apps and web databases were retired from Microsoft 365 and SharePoint Online (creation stopped June 2017, remaining apps shut down by April 2018). Desktop .accdb files were not part of that shutdown. Microsoft said it would continue to invest in Access desktop databases. https://support.microsoft.com/en-us/access/access-services-in-sharepoint-roadmap accessed 2026-09-30.
- Access users can migrate data to Dataverse or Dataverse for Teams from Access (export and the migration tool). Not every Access data type is supported, and some limits differ. After migration, users can keep the Access desktop client. https://learn.microsoft.com/en-us/power-apps/maker/data-platform/migrate-access-to-dataverse accessed 2026-09-30. Type differences: https://learn.microsoft.com/en-us/power-apps/maker/data-platform/migrate-access-datatypes accessed 2026-09-30 (search extract).
Vendor / product features used (URL each): the Microsoft URLs above. No claim that Aurum has a ready Access-to-bexio or Access-to-Abacus migration.
Not verifiable, therefore left out: a single "Access is discontinued" date for Microsoft 365 subscription Access; Power Apps or Dataverse licence prices; a Microsoft statement that SharePoint Lists is the supported replacement for a multi-table desktop database (the Lists export note on the Access Services page is about retired web apps); performance complaints from a Microsoft Q&A thread.
