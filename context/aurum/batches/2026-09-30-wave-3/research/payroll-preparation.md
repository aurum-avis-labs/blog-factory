# payroll-preparation
Primary query DE / EN: Lohnvorbereitung automatisieren / prepare monthly payroll inputs automatically
SERP (top results seen, what they cover, the gap we fill): Swissdec explains the certified payroll program and the electronic declaration. HR blogs mix hiring, leave and payroll into one product tour. The gap is the office checklist before the run: hours, absences, overtime, expenses and mutations in one place, with the payroll software still calculating and transmitting.
Verified facts (one per line, each with URL and access date):
- ELM is the Swissdec salary standard (Lohnstandard-CH). It replaces filling many paper forms with one electronic salary declaration. One transmission can serve the chosen recipients. It also allows reporting of entries and exits to the AHV and withholding-tax mutations during the year. Access 2026-09-30. https://www.swissdec.ch/user-elm
- A firm needs internet access and Swissdec-certified payroll software. The association does not recommend a product. Access 2026-09-30. https://www.swissdec.ch/user-elm
- Master data for wages and employees must be kept current. Swissdec states the simplest way is to record mutations as they happen. Access 2026-09-30. https://www.swissdec.ch/user-elm
- The association states that it forwards data only to the intended recipients, does not process it further, does not store it in transit, and that each recipient gets only the data meant for them. Transmission is encrypted XML. It asks firms not to email salary data to recipients, ERP vendors or Swissdec. Access 2026-09-30. https://www.swissdec.ch/user-elm
- Salary-certificate transmission does not need recipient master data in the system. The firm does need its expense rules for a correct certificate. Access 2026-09-30. https://www.swissdec.ch/user-elm
Vendor / product features used (URL each): Swissdec user page only. No payroll-vendor screen is described. Aurum has not built a Swissdec connector.
Not verifiable, therefore left out: ELM version numbers and cut-over dates (the archive page was not used). Contribution rates, withholding-tax tariffs, and which absence code maps to which benefit. Any claim that a chat tool or a spreadsheet is "Swissdec-certified".
