SERP (top results seen, what they cover, the gap we fill): Agency pages quote day rates that we do not have sources for. Microsoft documents connectors and custom connectors. The gap is which work lands in which of our own day bands, and when a prebuilt connector means you should not pay for a custom interface.
Verified facts (one per line, each with URL and access date):
- Azure Logic Apps, Power Automate, Power Apps and Copilot Studio "offer over 1,000 connectors to connect to Microsoft and verified services". Custom connectors are for services that are not available as prebuilt connectors. A custom connector is a wrapper around a REST API so those products can talk to that REST or SOAP API. You need authenticated access, then an OpenAPI definition, a Postman collection, or a definition built in the portal. https://learn.microsoft.com/en-us/connectors/custom-connectors/ accessed 2026-09-30.
- The same "over 1,000" / custom-connector distinction appears on https://learn.microsoft.com/en-us/power-automate/developer/register-custom-api accessed 2026-09-30 (page date on the fetch: 2024-03-25).
Vendor / product features used (URL each): the connector pages above. Aurum price bands from WRITER-BRIEF section 8 only. Built and claimable by Aurum: Microsoft 365 (Graph, Outlook, Bookings, Teams), Google Workspace, Stripe. Not built: bexio, Abacus, vertical software.
